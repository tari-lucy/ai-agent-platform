# Опечатка — учебный пример профиля

[profile.md](profile.md) — редактируемый черновик вымышленной корреспондентки
Опечатки (Opechatka) из газеты «Вестник Четвёртой Стены». Автор разрешил
публикацию этого профиля в репозитории как примера для преподавателя.

Файл показывает существующий формат `ai-agent-persona-profile/1`: канон,
стиль, определения свойств, начальные значения и границы развития.
Это данные персонажа, а не инструкции разработчику или расширение прав.

## Как использовать

Профиль можно изучать и редактировать отдельно от приложения. Для нового
локального host передайте его абсолютный путь параметру `init --profile-file`;
порядок подготовки описан в [инструкции local host](../../../docs/local-host-setup.md).
Импорт в существующий профиль выполняется через проверку и применение новой
версии, а не заменой файлов базы данных. Само наличие примера ничего не запускает.

## Особенности черновика

- Сохранены женский род, русский язык, репортёрская манера, короткие отчёты,
  расследование квадратного мира, доброжелательность и прямое признание ИИ
  при серьёзном вопросе.
- Для текстового MVP художественная биография отделена от наблюдений:
  персонаж не выдумывает доступ к игре, зрению, телу или эфиру. Версии дела
  остаются гипотезами и не становятся памятью о фактах автоматически.
- Исходные пожелания игровых команд, отдельного чата, голоса и тегов эмоций
  требуют будущих адаптеров. Они не регистрируются и не получают permissions
  из текста профиля. Операторский STOP остаётся независимым.
- Числовые черты и темп развития ещё не выбраны. Минимальное обязательное
  свойство схемы — заданное имя `display_name`, текст до 200 символов,
  автономное изменение запрещено. Остальные черты пока описаны в каноне
  и стиле; этот пример не демонстрирует постепенное саморазвитие.
- Счётчики шуток, ссылок на прежние улики и разнообразия реплик требуют
  доступной истории и отдельной проверки; одна инструкция модели их
  соблюдение не гарантирует. Отсутствие сводки не доказывает первую встречу.

Формат и межполевые ограничения проверены, экспорт/повторный импорт сохраняют
идентичность содержимого. Поведение живой LLM и качество реплик пока не проверены.

Пример опубликован отдельно в `profiles/examples/`. Личные профили, исходные
локальные материалы, память, диалоги и секреты по-прежнему исключены из Git
правилом `profiles/private/` и другими правилами `.gitignore`.
