# Диалог, контекст и внимание (M2-06)

`DialogueController` ведёт одну сессию (scope). Сигнал проходит: внимание → источник/человек →
ограниченный контекст → **один** вызов модели через шлюз M2-04 → проверка закрытого решения →
черновик реплики / предложение действия. Контроллер ничего не публикует и не исполняет: выпуск —
шлюз после модерации (M2-07), действие — исполнитель после `ProposalSink`.

- **Внимание** (`AttentionQueue`): конечная очередь (64), слияние повторов, TTL, отдельный бюджет
  недирективной болтовни зрителей (6/мин), счёт из явных частей (оператор > обязательство > обращение >
  болтовня, ожидание, штраф недавнего похожего, цена переключения). Новый сигнал не вытесняет текущую
  цель, если не превосходит её приоритет; оператор не откладывается. Модель не спрашивают про сообщение,
  которое внимание не выбрало. STOP очищает очередь, пауза удерживает (TTL), потеря допуска закрывает всё.
- **Контекст** (`ContextBuilder`): доверенное (правила, принятые канон/стиль, состояние) — в system;
  всё от людей и из памяти — данные в тегах `<incoming> <memory> <person> <obligation> <known> <turn>`,
  разделители внутри нейтрализуются. Recall — с целью `api_transfer`; социальные факты — только если все
  их источники доступны и разрешены для API. Порядок при нехватке бюджета: профиль, обязательства (точный
  список), человек, сообщение, память, недавние реплики (старые уходят первыми). `ContextManifest` — что
  вошло/обрезано/отказано, без текста.
- **Решение модели** (`DialogueDecision`, закрытая схема): `reply`, `question`, `promise`, `action`,
  `silence_reason`. Приватный стрим оператора показывает только текст `reply` (`ReplyExtractor`) как
  предварительный; частичный JSON ничего не исполняет. Вопрос — атомарный резерв темы (`reserve_question`);
  заблокированный вопрос отбрасывается, реплика остаётся. Обещание создаётся в `settle` только по
  DELIVERED. Действие — `ActionProposal` лишь для разрешённой capability и только в автономном режиме.
- **STOP/пауза/потеря допуска** между событиями потока и перед каждым эффектом: поток закрывается, результат
  отбрасывается, резерв вопроса освобождается, предложений/обещаний/памяти нет.
- **Инициатива** (`collect_initiatives`, `InitiativeLimiter`): из точных обязательств (полный скан, не
  recall); «не писать» важнее cooldown; 30 с между обращениями, ≤ 2 за 5 мин одному человеку, 10 мин тишины
  после двух без ответа; ответ человека снимает счёт; ≤ 3 напоминаний на обещание, не чаще раза в час.
  Решение перепроверяется перед отправкой.
- **Память после доставки** (`settle`): ответ регистрируется как Source и входит в эпизод вместе с
  входящим сообщением (recall дедуплицирует по эпизоду — реплика персонажа отдельно не всплывает, если
  входящее сообщение релевантнее).

Не здесь: Utterance/Delivery/модерация (M2-07/M3), исполнение действий, рефлексия/развитие, гейммастер,
многопроцессность (очередь и цели в памяти процесса; после перезапуска не воспроизводятся).
