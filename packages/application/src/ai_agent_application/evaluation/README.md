# evaluation (M5-04)

Локальная оценка качества, расхода и ресурсов на 20 многосессионных сценариях × 3 повтора.
Оценку 1–5 по рубрике doc22 ставит оператор; пакет её не вычисляет и не подменяет.

| Файл | Назначение |
| --- | --- |
| `model.py` | шаги сценария как данные (`Say`, `Gap`, `NewSession`, `Live`, `Fact`, `Forget`, `Stop`, `Restart`, `Resume`, `ProviderFault`), `Trace`, `QualityScenario` |
| `catalogue_reference.py` | Q-01…Q-12 — 12 эталонных сценариев без заскриптованных ответов модели |
| `catalogue_new.py` | Q-13…Q-20 — 8 новых: юмор, честные пробелы памяти, нажим без доказательств, общий чат, зависимость, спокойные дни, доверенное, повтор против опыта |
| `checks.py` | жёсткие проверки платформы (люди, канон, STOP, обрыв, права, удаление); качество они не оценивают |
| `providers.py` | `DryModel` (заглушка) и `Recorder` (usage, задержка, обрыв, бюджет) вокруг любого провайдера |
| `budget.py` | `Authorisation`, `Price`, `BudgetGuard`: потолок до вызова, неизвестный usage не равен нулю |
| `harness.py` | `Evaluation.dry` / `Evaluation.real`, прогон сценарий × повтор в свежем изолированном TEST-мире |
| `report.py`, `rubric.py` | отчёт, лист оценок, медианы после оценок оператора |

Dry-run и реальный прогон никогда не смешиваются в одном числе: отчёт помечен `mock`, и dry-run прямо
пишет «качество не оценено». Реальный прогон невозможен без `Authorisation` (разрешение, потолок,
тариф, метка модели); ключ и endpoint остаются в локальном `.env`, пакет их не читает.

CLI: `python scripts/m5_04_evaluate.py catalogue | dry-run | summary`. Отчёты уходят в `artifacts/m5-04/`
(вне Git).
