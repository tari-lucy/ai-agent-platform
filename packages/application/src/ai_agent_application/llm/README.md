# LLM-шлюз (M2-04)

`LLMGateway.generate` исполняет одно задание роли через `LLMProvider` (адаптер в
`adapters/llm`). Не исполняет ничего: инструменты провайдеру не передаются, а результат
существует только после завершающего события провайдера.

- Роль → `ResolvedAssignment` (`resolve_assignment`): подключение настроено и не `failed`,
  требуемые capabilities есть, область и параметры (`llm.generation-parameters`) совпадают,
  резерв объявлен назначением и той же роли. Модель, endpoint и ключ — конфигурация
  (имена `AI_PLATFORM_*`), не код. `unverified` допускается и остаётся видимым.
- Поток: `Started / Delta / Finished / UsageReported`. `completed` только после `Finished(stop)`;
  оборванный, обрезанный (`length`), отфильтрованный и tool-call поток — не результат.
  Показанный текст остаётся в `preview`, `text`/`parsed` пусты.
- Повтор: максимум 2 попытки на назначение, только при RATE_LIMITED/TIMEOUT/TRANSIENT и пока
  оператору не показан ни один символ; пауза растёт, Retry-After ограничен 30 с, jitter 0.75–1.25.
  Резервное назначение — только при отказе подключения/конфигурации/аутентификации/возможности или
  исчерпании повторов, видно в `used_fallback` и в отчётах попыток. Цепочка ≤ 3, циклы запрещены.
- Отмена: `cancel: asyncio.Event`, отмена задачи и `Admission` (доверенная проверка
  JobOwner.verify + scheduler.verify) закрывают поток, поздние события отбрасываются, результат после
  STOP не действует. Каждая попытка один раз попадает в `AttemptSink` (также при отмене) —
  это вход журнала M2-05.
- Usage: берётся последний отчёт провайдера (замена, не сложение); нет отчёта — `unknown`, не 0.
  cached/reasoning — подмножества родителя. Статус `unknown` для timeout/обрыва без ответа.
- Результат по схеме: целый JSON-документ, без fence, дублей ключей, NaN, лишних полей; плохой
  результат — `MALFORMED_RESULT`, повторного вопроса нет (платная попытка).

Не здесь: планировщик ресурсов (вызывающий держит BudgetLease вокруг `generate`), JobOwner/claim,
тарифы и журнал (M2-05), модерация (M2-07, другая модель), контекст диалога (M2-06).
