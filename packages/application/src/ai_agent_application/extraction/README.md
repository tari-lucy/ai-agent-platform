# Извлечение доказательств и консолидация (M3-01)

`Extractor.extract(scope, source_ids)` просит модель (роль `extractor`, закрытая схема
`ExtractionResult`) предложить утверждения; валидатор решает, что сохранится через `MemoryService.record_claim`.

- Источники: только существующие в области, доступные, с правом `api_transfer`; иначе пропуск с причиной
  и в запрос не попадают. Текст источников — данные в тегах (разделители нейтрализуются).
- Каждое предложение цитирует источник **дословно** (сверка со стором, пробелы нормализуются);
  неизвестный источник или цитата не из источника — отказ.
- Тип знания выводится из provenance источников, модель может лишь понизить: наблюдение → `observed`,
  слова участника/оператора → `reported` (содержимое хранится как «По словам X …»), `canon` — только из
  источника типа `operator-canon`, simulation — только в тестовой области. Всё, что создал персонаж или
  модель (реплики, сводки, рефлексия, дневник, посты, `MODEL_PROPOSAL`/`INTERPRETATION`), — *self-derived*:
  можно процитировать, но независимым доказательством оно не считается и выше `interpretation` (≤ 0.4) не поднимает.
- Независимость считается по «опыту» (эпизод), а не по числу источников: пересказ, пост и сводка одного
  эпизода — одно основание. Потолок уверенности: reported 0.6 → 0.8 при ≥2 независимых опытах,
  observed 0.9 → 0.95, hypothesis/interpretation 0.4; заявленная моделью уверенность обрезается.
- Противоречие: `contradicts` только на записи, показанные модели; обе позиции сохраняются со связью с двух сторон.
- Повтор не создаёт дублей (id из субъекта, текста и источников).
- Сбой, обрыв, невалидный JSON, отмена — ничего не пишется; допуск (STOP/пауза) проверяется до вызова
  и перед каждой записью.

`Consolidator.summarise` — сводка периода как интерпретация (`Summary` с префиксом и `analysis_id`,
цитирует источники, идемпотентна). `Summary` не `Source`: её нельзя процитировать как доказательство.

Не здесь: извлечение эпизодов, слияние независимых подтверждений в одну запись, семантическая проверка
смысла утверждения относительно цитаты, развитие/рефлексия (M3-03).
