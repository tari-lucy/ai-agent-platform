# Журнал попыток LLM, тарифы и стоимость (M2-05)

Владелец записей — `Owner.LLM`. `UsageLedger` хранит `LLMAttempt`, `Tariff`, `CostCalculation`
в основной БД (Redis не владелец финансовой истории). Вход — `AttemptReport` шлюза M2-04
(через `AttemptSink`); промптов, ответов, endpoint и ключей в записях и проекциях нет.

- Одна попытка — одна запись: id выводится из `attempt_id`, повтор квитанции, другой процесс или
  повторная команда находят её, а не создают новую оплаченную попытку. Реальный повтор вызова
  имеет другой `attempt_id` и учитывается отдельно.
- Поздние наблюдения уточняют, не складываются: итоговый usage провайдера заменяет оценку/частичный,
  слабее известного не становится, два полных расходящихся отчёта — `IDEMPOTENCY_CONFLICT`.
  `unknown` → терминальный статус допустим; терминальный статус не переписывается; usage после
  STOP/отмены принимается. Другая роль/модель/назначение/старт при том же id — конфликт.
- Тариф — на (подключение, модель), каждое изменение — новая версия; `effective_at` не уходит назад.
  Попытка запоминает версию, действовавшую на её старте; изменение цены прошлое не переписывает.
  Позднее/исправленное — только явным `calculate(..., repin=True)`: новая версия расчёта, старая
  остаётся читаемой.
- Цена: cached ⊂ input, reasoning ⊂ output — считаются один раз (`total − подкатегория` по ставке
  родителя + подкатегория по своей ставке или по ставке родителя). Нет тарифа, usage или нужной
  ставки — `partial` (нижняя граница известного) или `unknown` с `amount=None`, не 0.
  Реальный 0 токенов не требует ставки. Деньги — `Decimal`, строка без экспоненты, 10 знаков.
  Модель для цены — сообщённая провайдером, иначе запрошенная; нет её тарифа — неизвестно.
- Проекции: `summarise` (период, роль, модель, подключение; work/test раздельно и в общем итоге;
  деньги по валютам, `complete=False` при неизвестном usage/цене) и `history` (все попытки, включая
  отменённые и неизвестные).

Не здесь: бюджет и оповещения 50/80/100 % (оператор/M1-06), HTTP/панель, запись `running` до вызова
(шлюз сообщает только завершённые попытки), курсы валют, сверка со счётом агрегатора.
