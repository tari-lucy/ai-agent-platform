# Рефлексия, валидатор развития, история и откат (M3-03)

`DevelopmentController` (пишет владелец persona — он владеет `CharacterState`) принимает **предложения**
изменения свойства (`Candidate`, из рефлексии или от оператора) и ведёт `StateChange`:
PROPOSED → READY | AWAITING_APPROVAL | REJECTED | CONFLICT → APPLIED | CANCELLED.

- Проверки: свойство из принятого профиля (не отношения), значение в диапазоне, есть изменение, неопределённость
  ≤ 0.6, версия состояния совпадает (`expected_version`), сюжетные правила (hard → отказ, неуверенность → оператор),
  основания — прожитые эпизоды (observation в work, simulation в test), независимые первичные источники, ещё не
  «потраченные» на это свойство; шаг ≤ `max_step_per_episode` × число новых независимых эпизодов, сумма за окно ≤
  `max_step_per_window` (откатанные изменения бюджет не тратят), эпизодов ≥ `min_independent_episodes`.
- Маршрут: автономно только для автономного, не identity, числового свойства; identity, `autonomous=false` и
  текстовые — `AWAITING_APPROVAL`, применяет только решение оператора (`decide`); ожидание не равно согласию.
  Оператор не обходит проверку диапазона.
- `apply`: READY — только при ACTIVE/OPEN/autonomous/допуске (пауза, STOP, наблюдение оставляют READY); одна
  транзакция «новая версия состояния + APPLIED» с CAS; повтор доставки — тот же `StateChange` (`duplicate`), другой
  payload — `IDEMPOTENCY_CONFLICT`; после применения ожидающие изменения на старой версии → CONFLICT.
- Откат: `preview_rollback` показывает цепочку зависимых применённых изменений (новые первыми), текущее/
  восстанавливаемое значение и инвалидируемые ожидающие; `rollback` требует `operator_decision_id` и digest из
  предпросмотра, создаёт **компенсирующие** записи (`kind=rollback`, `revision_of`), историю не переписывает.
- `Reflector`: триггер — прожитый опыт; триггеры из производных id (`refl-`, `chg-`, `rollback:`, `summary-`)
  отвергаются, один триггер — одна рефлексия, интервал ≥ 10 мин, пауза/STOP откладывают без вызова модели;
  «ничего не менять» — полный ответ; основания, которых не видела модель, пропускаются; сама рефлексия ничего не
  применяет.

Не здесь: проверка проявления ожидаемого поведения, панель, уведомления оператору, развитие отношений (social),
схема `development.patch` регистрируется composition (`register_development_extensions`).
