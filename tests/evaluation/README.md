# Проверки M5-04 (evaluation)

Вымышленные люди и сцены; настоящая SQLite, заглушка вместо модели, виртуальное время. Без сети и ключей.

```bash
export PYTHONPATH=apps/core/src:apps/worker/src:packages/contracts/src:packages/domain/src:packages/application/src:packages/adapters/src
python -m pytest tests/evaluation -q
```

- `test_catalogue.py` — 20 сценариев (12 эталонных + 8 новых), все многосессионные, рубрика покрыта, тексты синтетические, повреждённый каталог отвергается.
- `test_rubric.py` — проверка листа оценок, `null` = не относится, медиана, цель ≥ 4, устойчивый цикл, нет вердикта до полного листа.
- `test_harness.py` — dry-run всех 20, воспроизводимость, нет сети, обрыв без полуфразы, STOP/перезапуск, раздельные люди, закрытая заметка и удаление, потолок бюджета, неизвестный usage, отказ без разрешения, отчёт без промптов.

Не проверено: реальный провайдер и любая оценка качества (её ставит оператор), recall (отдельные пробы M0-05).
