решения. Обновляется вместе с планом.

## Принятые решения

D01–D46 подтверждены последовательным обсуждением. D47–D51 выбраны в рамках
поручения пользователя 2026-10-13 довести планирование самостоятельно;
D52 отвечает отдельному запросу об инструкциях нескольким кодинговым агентам.
Технические defaults не выдаются за отдельное согласие по каждому значению.

## Итог

[Финальный аудит](25-preimplementation-readiness.md) связывает R01–R26 с
задачами/критериями. [Каталог](24-mvp-implementation-plan.md) готов для выдачи
Codex/Claude Code; [инструкции](27-coding-agents-workflow.md) определяют
владение файлами, ветки и integration gates. Никаких planning blockers до M0
не осталось. Непроверенные свойства стека и модели названы прямо и имеют
эксперименты/fallback; они не выдаются за готовую реализацию.

Практические выводы старого прототипа остались входными требованиями:
отдельная навигация/поведение, finite recovery, инициативность по контексту,
социальная память, независимые game/voice/avatar, локальные секреты и
конфигурация. Код/архитектура NetTyan не переносились.
