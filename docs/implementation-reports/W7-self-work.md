# W7: самостоятельная работа — будильники и разговор-дневник

Claude Code, 2026-10-26. План: [doc31 §7](../31-agent-workspace-v2.md), D74.
Ветка `claude/w7-self-work` от W5. Инструкция: [agent-workspace.md](../agent-workspace.md).

## Что сделано

- **Контракт.** `WakeTimer` (владелец activity): разговор, срок, причина, состояние
  pending/fired/cancelled, номер сообщения. У сообщения разговора новый говорящий
  `wake` (и в расшифровке панели). Сгенерированные контракты обновлены.
- **Владелец сессий.** `set_timer` (не больше 16 ожидающих, срок от часов владельца,
  повтор запроса возвращает тот же будильник), `timers`, `wake` (одной транзакцией:
  сообщение `wake`, курсор разговора, будильник fired; закрытый разговор — cancelled).
  Сообщение `wake` во всех местах — вход хода, как сообщение оператора; ответ агента
  ссылается на него (`reply_to`), в контексте модели — сообщение пользователя.
- **Операция `wake_me`** (минуты 1…10080, причина ≤ 500) в инструментах платформы, только
  при включённой самостоятельной работе; находит или открывает разговор
  «Самостоятельная работа».
- **Такт.** `AutonomousWake` на такте runtime (раз в 15 с): только ACTIVE, OPEN,
  autonomous, рабочая память; вне тихих часов; лимит в час. Текст будильника сохраняет
  владелец памяти (provenance model_proposal, автор agent), затем `wake`; дальше —
  обычный драйвер разговора с теми же бюджетом, правами, журналом и STOP.
- **Окно (патч 18).** Сообщение будильника — входящее с пометкой ⏰.
- **Настройка:** `--self-work`, `--wake-max-per-hour`, `--quiet-hours START-END`.
  Агент узнаёт про `wake_me` из описания среды только при включённой функции.
