# Подготовка репозитория к показу

2026-10-26. База — main `81b49b4`, включая опубликованные поставки Claude.
Изменяются только документация, ignore-правила и исторические debug-дубликаты.
Личный deployment, образы, память, права и незавершённые ветки не обновлялись.

## Репозиторий

- Отслеживаемые исходники до уборки: 1071 файл, около 10,13 МиБ.
- Удалены четыре файла `deploy/opencode-ui/dev/`: исторические скрипты со
  scratchpad-путями и копия адаптера. Каноническая серия патчей, команды сборки,
  приёмочные тесты и лицензии сохранены. Ссылки и историческая заметка уточнены.
- README ведёт к короткому обзору проекта и новому плану рабочего пространства.
  План и наличие кода не объявляются проверенным локальным включением.
- Ignore дополнен локальными worktrees и стандартными результатами проверок.
- Выполнен просмотр tracked-файлов на локальные пользовательские пути и
  типовые секретные строки. Это эвристическая проверка текущего дерева,
  не полный аудит истории Git и не гарантия отсутствия любых секретов.

## Локальная уборка

Удалены только точные allowlisted-пути: девять старых контекстов Docker-сборки
в завершённом checkout Codex и три корневых кэша mypy/pytest/ruff. Каждый
контекст содержал лишь Dockerfile, исполняемый OpenCode и доверенные модули.
Перед удалением проверены абсолютные пути, состав и отсутствие reparse/symlink.
Суммарный логический размер удалённых файлов — **1619,4 МиБ (1,58 ГиБ)**.

Не удалялись: worktrees, виртуальные окружения, исходники upstream, Docker
images/volumes, резервные копии, ledger, данные персонажа и `.env`.
Кэш Bun оставлен: в нём обнаружены ссылки. Крупные checkout не считаются мусором
только по размеру — там могут находиться WIP и необходимые окружения.

## Проверки и передача

Проверяются diff, относительные ссылки изменённых документов и содержимое
чистого исходного архива, созданного `git archive`. Код и runtime не менялись,
поэтому тестовый suite, Docker-пробы и платные вызовы не запускались.

Для показа предназначены GitHub и архив tracked-дерева; не полная локальная
папка разработки. Архив не содержит `.git`, `.env`, `runtime`, личные настройки,
зависимости или память. Это исходники, а не готовая установка с UI и моделями.
