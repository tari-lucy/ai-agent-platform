# Включение приватного GM и ограниченная live-проверка

База: main 31ed01f. Координатор, codex/private-gm-live-activation.
Оператор согласовал публичное направление Опечатки, включение GM и платную пробу.

## Найдено и исправлено

- Story-screen отвечал обычным текстом вместо закрытого JSON. Строгий парсер
  отклонял результат, линия оставалась paused, предложения не создавались.
  Теперь перечень правил передаётся JSON-данными, область оценки определена
  явно, текст предложения находится в нейтрализованном блоке proposal.
  Запрет в границах не интерпретируется как предложение запрещённого действия.
  Неизвестные IDs правил, malformed result и uncertain по-прежнему закрывают
  предложение; проверка схемы и правила не ослаблены.
- Потолок вывода GM 512 токенов заканчивался без видимого результата.
  При допустимом потолке 1024 модель завершила результат (912 output tokens).
  Это настройка существующего LiveConfig, не новый обход ограничений.
  В рабочем host планируется ceiling 1024 и привязки GM/story-screen 1024;
  прежние привязки character/extractor/consolidator/reflection 512 сохраняются.
- Добавлен публичный пример gm-boundaries.txt; направление gm-line.txt одобрено
  оператором. Частные host.json, модельные ответы, БД и .env не добавляются в Git.

## Live-проба

API Token / claude-sonnet-5, HTTPS через штатный loader/adapter. Отдельный
одноразовый host с публичным профилем и вымышленным подтверждённым разговором.
Первый ответ для подготовки опыта синтетический; в рабочую память ничего
не записано. Production init/serve composition, owners/jobs/usage/права те же.
GM-задача подана явно координатором в isolated composition: ожидание часового
интервала и автономное срабатывание таймера живой пробой не проверялись.

Первоначальный потолок четыре внешних вызова расширен до семи после сообщения
оператору о диагностике формата. Автоматических HTTP-повторов нет, счётчик
ограничивает весь набор попыток, включая отказы и повтор подготовки после
исправлений. Израсходовано ровно семь внешних вызовов: пять story-screen,
два game-master. Три первоначальных screen-ответа не прошли формат, один
GM-ответ не завершился в 512; финальные line screen, GM draft и offer screen
приняты. В SQLite есть открытая линия и Opportunity в OFFERED.

Содержание финального предложения вручную просмотрено на вымышленных данных:
вернуться к пропущенной запятой, обдумать, заслуживает ли она места в рубрике,
сохранить различие наблюдения и сенсации. Границы оставляют персонажу выбор,
не обещают публикации/встречи и не предрешают реакцию собеседника.

Usage семи внешних попыток complete: 6997 input и 2281 output tokens.
Синтетические подготовительные ответы имеют unknown usage и не считаются
реальными API-вызовами или бесплатными ответами провайдера. Денежный биллинг
кабинета не сверялся. Вспомогательный private script после последней пробы
не перезаписал create-only файл отчёта (FileExistsError); наличие OFFERED,
финальные tokens и число попыток проверены по текущим SQLite записям и
независимому wire-counter. На результат применения предложения это не повлияло.

## Проверки и ограничения

Три локальные проверки classifier — passed (пустые правила, закрытие на
uncertain/неизвестном ID/отказе, нейтрализация tag delimiter). Полный GM→персонаж
путь — один synthetic сценарий passed. Финальный точечный прогон после исправления
assert о принятой форме нейтрализации: 2 passed, 25.98 с; ранее прошедшие два
unit-теста повторно не запускались. Sandbox unit-запуск был остановлен, принят
короткий native Windows прогон. Платных вызовов эти тесты не делают.
Ruff и strict mypy 215 source files чистые. Полный suite не запускается.

Новый живой ответ персонажа с offer не покупался: бюджет пробы исчерпан.
Live-доказательство ограничено созданием проверенного OFFERED, а передача
предложения и решения персонажа проверены synthetic. Один пример не доказывает
стабильное качество модели. Restart по-прежнему STOPPED; каждый явный START
начинается с паузы GM, снятие паузы — существующая операторская команда.
Без входящей реплики GM не пишет пользователю сам.
