## Приёмка

| Критерий M2-04 | Результат |
| --- | --- |
| Полный / оборванный stream | полный → `completed`, текст, usage, сообщённая модель; обрыв соединения (loopback RST), поток без finish_reason, `length`, content_filter, tool_calls → `incomplete/failed`, `text`/`parsed` пусты, показанный текст в `preview` |
| Отмена | event, отмена задачи, отзыв допуска: поток закрыт, поздние события не доставлены, отчёт попытки `cancelled`, usage `unknown` (не 0), loopback-сервер видит закрытие сокета; результат после STOP не действует |
| Конечный повтор | ≤ 2 попытки на назначение, только RATE_LIMITED/TIMEOUT/TRANSIENT и пока ничего не показано; пауза ≤ 30 с, jitter 0.75–1.25; каждая реальная попытка — отдельный отчёт |
| Некорректный результат | не-JSON, fence, дубли ключей, NaN, лишние поля, чужие типы, обрезанный JSON → `MALFORMED_RESULT`, `parsed=None`, без повторного платного вопроса; tool-call фрагменты не пересылаются |
| Настраиваемые endpoint/модель | имена переменных из подключения, модель из назначения; endpoint только https (http — loopback), без userinfo/query/fragment; редирект не выполняется |

Дополнительно: ошибки адаптеров и HTTP не содержат ключа, endpoint, заголовков и текста ответа;
резерв виден (`used_fallback`, отчёты с исходным и фактическим назначением), не применяется после показа
текста; цепочки с циклом/длиннее 3 отвергаются до вызова.

Мутации защит (21): поздние события после STOP, повтор/резерв после показанного текста, финальный допуск,
замена usage вместо сложения, `unknown` статус, текст после завершения, `length` как stop, пустой ответ,
дубли JSON-ключей, предел попыток и паузы, редиректы, http/userinfo, утечка текста ошибки, tool_calls,
cached > input, роль резерва, failed-подключение, capability — каждая роняет тест (пять выживших
исправлены тестами).

## Решения и допущения

1. Шлюз не знает про Job/Redis/scheduler: доверенный исполнитель сам держит claim и BudgetLease и передаёт
   `Admission` (verify JobOwner + scheduler.verify). Так порядок вызовов из README scheduler сохраняется.
2. Журнал попыток и тарифы — M2-05: шлюз только отдаёт `AttemptReport` в `AttemptSink`.
3. Статус `unknown` для timeout/обрыва без ответа: стоимость и эффект неизвестны, usage не обнуляется.
4. Результат — только целый строгий JSON; fenced-блоки отвергаются (осознанно строже, чем многие модели).
5. Модератор — отдельное назначение другой роли; запрет «модель персонажа = модератор» проверяет M2-07.

## Не проверено / ограничения

- Реальный агрегатор: совместимость, usage при обрыве/отмене, модели, лимиты, цены; платные вызовы не делались.
- Внешний Redis/job-путь, несколько процессов, Windows/Docker, нагрузка.
- Structured output/tools/Responses API: провайдеру не передаются.
- Локальная оценка токенов не считается (usage остаётся `unknown`, если провайдер его не прислал).
