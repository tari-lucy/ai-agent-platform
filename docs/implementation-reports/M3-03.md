## Приёмка

| Критерий M3-03 | Результат (реальная SQLite, persona + memory) |
| --- | --- |
| Bounded changes | диапазон, «есть изменение», неопределённость ≤ 0.6, шаг ≤ `max_step_per_episode` × число новых независимых эпизодов, сумма за окно ≤ `max_step_per_window` (старые шаги выходят из окна, откатанные не тратят), эпизодов ≥ `min_independent_episodes`; основания — прожитые, независимые, не потраченные ранее на это свойство (собственные реплики/сводки/модельные источники и пересказ уже учтённого опыта не считаются) |
| `expected_version` | несовпадение базы → CONFLICT; применение — одна транзакция с CAS состояния и записи изменения; сдвиг состояния мимо контроллера блокирует apply; после применения ожидающие на старой версии → CONFLICT, повтор доставки — тот же `StateChange`, иной payload — `IDEMPOTENCY_CONFLICT`, повторный apply отказан |
| Identity требует оператора | identity, `autonomous=false` и текстовые свойства → `AWAITING_APPROVAL`, применяются только `decide(approve)` с `operator_decision_id`; молчание не применяет; оператор не обходит диапазон |
| Pause / STOP | READY применяется только при ACTIVE/OPEN/autonomous/допуске (пауза, STOP, наблюдение, потеря допуска оставляют READY); рефлексия в этих режимах откладывается без вызова модели; операторское решение — отдельная явная команда |
| Preview compensating rollback | `preview_rollback` показывает цепочку зависимых применённых изменений, текущее и восстанавливаемое значение, инвалидируемые ожидающие; `rollback` требует решения оператора и digest предпросмотра, создаёт компенсирующие записи (`kind=rollback`, `revision_of`), история и события не переписываются; повторный откат отказан |
| Рефлексия | «ничего не менять» — полный ответ; один триггер — одна рефлексия, интервал ≥ 10 мин; производные триггеры (`refl-`, `chg-`, `rollback:`, `summary-`) отвергаются; применение не запускает рефлексию; основания, которых модель не видела, пропускаются; идея проверяется как любое предложение |

## Решения и допущения

1. Контроллер работает под principal владельца persona (он владеет `CharacterState`); `StateChange` не имеет владельца
   в каталоге и пишется им же.
2. Шаг за эпизод масштабируется числом новых независимых эпизодов (0.02 × n); «значимый эпизод» = прожитый
   независимый непотраченный.
3. Неизвестный эпизод нельзя сохранить даже как отклонённое предложение (контракт требует ≥ 1 источника) — вызов
   отвергается `INVALID_ARGUMENTS`.
4. Откат восстанавливает значение до *целевого* изменения и компенсирует все последующие применённые изменения этого
   свойства (одной версией состояния); частичный откат в середине цепочки не предусмотрен.
5. Проявление ожидаемого поведения (`expected_manifestation`) хранится, но проверяется следующей подходящей ситуацией
   в поведении/M3-04, не здесь.
