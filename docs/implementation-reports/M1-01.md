Чистая проверка business результата различает scope/run/control_epoch,
profile/policy versions, operation/command/attempt/lease version и expiry.
Она не выполняет транзакцию или воздействие; актуальные значения передаёт владелец.
Удалённый источник может остаться недоступной ссылкой основания, но не
возвращается как recall fragment со старым текстом. Applied change требует
новой версии; WAITING/reservation имеют условие/срок; неизвестный usage/cost
не становится нулём. Реплика проверяет SHA-256 точного текста; moderation DTO
различает subject/moderator models. STOP receipt возвращает state/epoch/run и
неподтверждённые ресурсы; STOPPED с непустой неизвестностью отклоняется.

## Граница результата и следующие задачи

OpenAPI — исполнимый offline generator и согласованный path/type contract,
не запущенный HTTP runtime. Runtime routes остаются остановленным scaffold.
Ни авторизация, ни переходы supervisor, ни transaction/outbox/retry, ни
реальная модерация не объявляются проверенными этой задачей: M1-02/03/04/05
и M2-07 выполняют их через эти схемы. Security declarations в OpenAPI
не защищают endpoint без handler/middleware. Live provider, платные вызовы,
игра, эфир, реальные профили и sleep/crash runtime не проверялись.

Минимальные дополнительные технические пределы: ID 128 / brief metadata 512
chars, extension 64 КиБ, depth 32. Они ограничивают общие doc23 caps;
не заменяют runtime budgets/permissions. Первые конкретные schemas профиля,
инструмента/LLM parameters регистрируют назначенные владельцы. Неизвестная
регистрация отклоняется, обходного arbitrary JSON command path нет.

M1-02 может использовать принятые ID/scope/schema/version/status DTO.
Нужны одна линейная миграция, scope-aware repositories, atomic expected-version
write + outbox + scoped dedup uniqueness; leases/result freshness проверяются
в транзакции владельца. Worker не получает живую БД. Исполнение preview-плана
сверяет актуальные dependencies/version/expiry; схема сама это не доказывает.
Преобразование untrusted input делать через bounded codec, а не model_construct.
Блокирующих противоречий для M1-02 не обнаружено.
