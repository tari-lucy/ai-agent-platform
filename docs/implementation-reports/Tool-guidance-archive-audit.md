# Проверка архивного хода и описание инструментов

2026-10-26. Поручение оператора: проверить фактическую работу с загруженным
архивом и объяснить персонажу доступные возможности, сохранив самостоятельность.
База — main `ee23ace`. Код enforcement, контракты и выданные права не менялись.

## Что установлено

Через авторизованные чтения владельцев проверены все страницы метаданных
попыток: 45 записей, список полный. Найдены четыре попытки со ссылкой на
операторский JAR, из них последняя успешная. В журнале нет ни одного helper
receipt; в полном файловом каталоге нет ни одного сохранённого Python-скрипта.
У связанных попыток нет result_files. Следовательно, подтверждённого исполнения
Python-разбора этого архива не было. Ссылка во входах означает происхождение
материала, а не доказательство чтения его содержимого.

Полный сырой trace каждого встроенного инструмента OpenCode не сохраняется.
Поэтому аудит не объявляет все технические утверждения ответа ложными и не
приписывает модели конкретный неизвестный вызов. Версия игры, порт и протокол
не проверены этим аудитом. Корректность части ответа сама по себе не доказывает
исследование кода. Отсутствие файла отчёта ошибкой не считается.

Личные тексты не внесены в Git. После отклонения автоматической проверкой
слишком широкого запроса аудит ограничен метаданными и зависимостями архива;
несвязанные текстовые материалы не читались.

## Изменение

Доверенное описание среды, которое добавляется к системному сообщению каждого
вызова модели, теперь получает фактическую helper-конфигурацию от session driver:

- При включённом helper: Python stdlib, save/run, точные ссылки входов, чтение
  receipt и выходов, пределы из RunnerTemplate. При отключённом helper он
  явно не рекламируется как доступный.
- Сеть none, container localhost не Windows, модельный gateway не общий
  сетевой доступ. Написать WebSocket-клиент не означает получить подключение.
- Внутри выданных прав персонаж сам читает материалы, пишет/исправляет скрипты
  и завершает поручение без подтверждения каждого подшага. Обращение — при
  действительно новом доступе, недостающем инструменте или неустранимой ошибке.
- Наличие материала, чтение, предположение и выполненное действие различаются.
  У технических выводов нужны основания; имя JAR и строки не доказывают протокол.
  Ответ в чате допустим без обязательного файла.

Инструкция не выдаёт Permission, не расширяет сеть, не отключает STOP и не
гарантирует послушание модели. Независимая проверка прав остаётся в владельцах.
Образ и родной UI не меняются; новые факты передаются существующим gateway.

## Применение

Код опубликован в main (`4864ca4`) и перенесён в отдельный deployment checkout.
Перед обновлением подтверждён штатный STOP без неподтверждённых ресурсов.
После обычного serve проверены STOPPED, доступность native UI и сохранение
ранее выданного Python Permission. Личный host не переинициализировался,
образ, бюджет и сроки разрешений не менялись. Для новой пробы нужен явный START;
платный запрос от имени оператора автоматически не отправлялся.
