# Обращения в панели: простые действия оператора

Исполнитель: Claude Code. Ветка `claude/tickets-ux`, base main `8a4a4c8`. Зона: экран
обращений (`apps/panel/src/ui/tickets/*`) и его тесты; shared-контракты и API-клиент не менялись.

## Результат

- Карточка: «Что случилось», «Чего агент ждёт от вас», состояние словами («Ждёт вашего
  ответа», «Агент работает над этим», «Закрыто без выдачи доступа»). Попытки, оценка, версии,
  идентификаторы — в раскрываемых «Подробностях».
- Ответ — поле и «Отправить ответ» (`ticket.reply` answer). Завершение — отдельное
  «Завершить обращение…» с объяснением и необязательным комментарием (resolve); прав не выдаёт.
- Запрос доступа: какая возможность (summary), зачем, области, срок, состояние подключения.
  Capability, binding (проверенное первым, иначе готовящееся; отозванное — никогда) и версии
  подставляются из актуальных записей; области — запрошенные в пределах manifest; уровень по
  умолчанию automatic (public_output — с решением оператора). «Разрешить…» → «Что произойдёт»
  (существующий preview) → «Подтвердить выдачу доступа» (execute). Отдельно «Отказать…» →
  «Отказать в доступе» (close, без Permission). Уровень, срок, области, ограничения — в
  «Подробностях решения».
- Результат явно: «Ответ отправлен…», «Обращение завершено. Права при этом не выдаются.»,
  «Доступ выдан до …», «Запрос закрыт без выдачи доступа.» Текст «разрешаю» прав не выдаёт
  (подсказка у поля ответа).
- Ошибки: конфликт версии — черновик сохраняется, кнопка «Обновить карточку»; выше потолка
  host — причина и что уменьшить; нет подключения или возможность не зарегистрирована —
  причина, «Разрешить» скрыто, ответ/отказ доступны. Пока отметка о прочтении (меняет версию)
  не применена, действия неактивны — быстрый клик не уходит со старой версией.
