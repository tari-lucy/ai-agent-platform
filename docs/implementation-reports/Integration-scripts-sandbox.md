# Интеграция Python-песочницы в обычный запуск

2026-10-26. Основа — пакет GLM `9d5a75f` от main `469a75d`.
Поставка использует прежних владельцев файлов, попыток, прав и runner;
нового реестра исполнения или отдельной памяти нет.

## Исправления при интеграции

- Helper-флаги CLI передаются именно `enable-work-sessions`, а не настройке
  файлов. Повторная настройка сохраняет пропущенные лимиты и период мониторинга.
- Предсуществующая чужая возможность не может быть принята за Python helper.
  Проверяются manifest/binding, а также метка протокола pinned-образа.
- Таймаут локального MCP больше предельного времени контейнера; завершение
  определяют runner, бюджет и STOP. Старые 60 секунд не обрывают разрешённый
  долгий скрипт посередине.
- Отдельное разрешение helper повторно проверяется после исполнения, включая
  результат только со stdout. Версии manifest/binding/Permission закрепляются
  при записи результата и receipt под существующей транзакцией владельца;
  TTL и текущий допуск проверяются заново. Узкий независимый review выполнен.
- При prepared/unknown helper исход сверяется с job, но новая автоматическая
  попытка того же входа не создаётся. Ошибка не обходится повторным исполнением.
- Добавлен локальный refresh harness: только три доверенных модуля поверх
  имеющегося образа, без установки пакетов. Проверяются исходный образ и слои
  результата. Полная сборка native Web UI не нужна.

## Проверки

- Mypy: 309 файлов, без ошибок.
- Wiring: финальный набор **5 passed**, включая CLI, сохранение настроек и гонку
  отзыва Permission перед commit. Helper/unit/protocol набор после исправлений:
  16 passed. Финальный protocol-набор с запретом обхода неизвестного исхода:
  10 passed. Полный suite не повторялся.
- Реальная Docker-проба использует обычные init/serve wiring и OpenCode/MCP,
  синтетический провайдер и вымышленный JAR размером 6 МиБ. Вход загружается
  через HTTP-владельца файлов; оба разрешения выдаются обычным решением по
  тикету. Проверяются stdlib zipfile, происхождение отчёта, отсутствие сети,
  non-root/read-only root, отсутствие host/docker socket/секретов, доставка,
  STOP во время следующего скрипта и restart STOPPED.
- Проба сначала нашла ошибку проверки TTL в интеграционном коде; исправлено.
  Следующий прогон разобрал архив и дошёл до STOP-части; исправлена гонка
  проверки уже удалённого контейнера и ожидание отдельной квитанции job в самом
  тесте. Финальный сценарий: **1 passed за 116 секунд**. Оба контейнера удалены,
  STOP завершён, restart STOPPED. Платных вызовов нет.

## Границы

Платных API-вызовов и чтения личного архива в проверках нет. Обработка
произвольного содержимого моделью не оценивалась. Это Python stdlib, без
установки пакетов, Java-декомпилятора или запуска кода архива. Возможность
конфигурируется, но Permission остаётся отдельным решением оператора.

Вход передаётся целиком в памяти; оценка пика хоста 3–4 размера входа остаётся
ограничением. Выходы публикуются только через владельца с актуальными правами,
версиями, происхождением и допуском; удалённое основание не восстанавливается.

Инструкция оператора: [Python-песочница](../opencode-python-sandbox.md).

## Локальное включение после gate

Интеграция опубликована в main (`1d13177`). Отдельный deployment checkout
обновлён штатным merge; работающий агент предварительно остановлен через STOP,
неподтверждённых ресурсов не осталось. Обновлён только доверенный harness
существующего локального образа; его digest метки соответствует исходникам.
Нативный UI сохранён без пересборки (принятая файловая поставка).

На локальном хосте helper подключён с потолками: 60 с wall, 10 с CPU,
256 МиБ RAM, 128 МиБ tmpfs, 32 МиБ входов, 64 КиБ выхода, до 8 вызовов за ход.
Остальные настройки хоста сохранены, включая модель, память, бюджет,
прогрев и параметры рабочего разговора. Потолок допуска — automatic до 7 дней.

Через владельца обращений создан один технический запрос «Разрешить
Python-песочницу» для `workplace.scripts`, области `inbox` и `projects`.
**Permission не выдан** — подтверждение остаётся оператору.

После обычного serve Edge подтвердил: карточка и кнопка «Разрешить…» доступны,
OpenCode открывается, виден START (состояние STOPPED). Личный архив не читался,
код из него не исполнялся, модель на личном хосте не вызывалась.
