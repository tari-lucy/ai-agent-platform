## Изменения и границы

- apps/panel: React/Mantine shell, HashRouter с семью областями,
  русские состояния, empty/error/недоступные функции, responsive layout.
  Редактирование, диалог/генерация, лабораторный runner, права и расходы
  этой задачей не реализованы; экран не изображает их работающими.
- Operator login/session restore/logout, cookie same-origin,
  CSRF только RAM, cache/session cleanup при logout/401/absolute expiry.
  Пароль очищается в форме сразу после submit и не помещается в Query/URL/
  storage/log. Cookie HttpOnly/SameSite принадлежит M1 core.
- Общий PanelApi импортирует canonical generated TS types без копии схем.
  Чтения/квитанции проходят defensive shape/scope checks до использования.
  HTTP JSON ограничен1MiB/15s, STOP6s; redirect/error закрыты.
  Мутации без automatic retry, command receipt проверяет request/scope.
  Чужие/raw сообщения ошибок не показываются.
- Query cache только RAM, ключ workspace/persona/memory_space/memory_mode;
  gc60s/stale5s, без focus/network retry/persistence. Одновременно доступны
  до8 auth scopes, только sessions/personas. Первая страница профилей limit50,
  неполнота помечается, display name пока заменён принятой persona_id.
- WebSocket same-origin/cookie, exact authorised partition subscription,
  до2 connections (выбранная область и активный owner), handshake10s,
  frame16KiB, до5 reconnects за lifetime; дедуп/версии до128.
  Повторное соединение перечитывает проекции, не повторяет команды/LLM.
  after_event_id/replay не используются, auth1008 требует проверки сессии.
- Постоянный STOP выбирает фактического owner независимо от просмотра,
  сохраняет agent/run/session fencing, не зависит от WS/ожидающего чтения.
  STOPPING/FAULTED, неподтверждённые ресурсы и неизвестный исход показаны явно.
  Более поздний owner snapshot обновляет прежний STOPPING; другой run
  не наследует квитанцию. Start/resume/внешние эффекты не запускаются.
- deploy/Dockerfile panel stage сохраняет repo layout для canonical import;
  .dockerignore допускает только generated/contracts.ts;
  scripts/verify-linux.ps1 включает export и Node tests в panel recipe.
  Python stages/Compose/resources/migrations/contracts/locks не изменены.
  package.json меняет только test script; dependency versions прежние.
- Тесты: apps/panel/tests (Node builtin runner) и tests/panel (Playwright);
  README модулей содержит команды и порты следующим screen owners.
