# Развитие Опечатки и обработка опыта после остановки

Координатор, 2026-10-19. База `cf9c045`, ветка
`codex/opechatka-development-catchup`. Прикладная настройка M3-03 и суточного
memory pipeline; новые интеграции и платные пробы не запускались.

## Что изменено

В публичный профиль добавлены шесть числовых черт на шкале 0..1:
любознательность 0.75, инициативность 0.45, осмотрительность 0.60,
гибкость версий 0.70, театральность подачи 0.60, доведение дела 0.65.
Определения, начальные значения и границы остаются редактируемыми данными профиля.
Минимум три независимых эпизода, шаг до 0.02 за эпизод и суммарно до 0.05 за
семь дней для каждой черты. Имя, канон и правила не становятся автономно
изменяемыми; новые инструменты/Permission не выдаются. Сохранить прежнее состояние
после рефлексии допустимо. Изменённый CharacterState попадает в следующий ответ.

Рефлектор видит названия, смысл, текущие значения и конкретные границы свойств.
Просит одну краткую правку за порцию; каждый результат по-прежнему проходит
существующие проверки опыта, диапазона, независимости, скорости, story-screen,
версий и текущего допуска. Это изменение состояния, а не обучение весов LLM.

## Независимость опыта

Обнаружено, что private Episode содержал всю историю, показанную модели.
Группировка объединяла через общие context sources последовательные новые
разговоры. Добавить только черты было бы недостаточно для накопления оснований.

Добавлен необязательный `Episode.experience_source_ids`: уникальное подмножество
полного sources, которое указывает владелец. ACK приватного диалога сохраняет
здесь текущую входящую реплику и точно доставленный собственный ответ.
Все контекстные sources сохраняются и проверяются на права/версии/TTL/удаление;
новое поле не ослабляет зависимость ответа или изменения от закрытого источника.
Собственный ответ не считается независимым свидетельством. Общий первичный
источник объединяет пересказы, как раньше. Группировка опыта и recall/reindex
используют подмножество. Старые эпизоды без него сохраняют консервативное
объединение по всем ссылкам; backfill и переинтерпретация старой памяти не делались.
JSON Schema, OpenAPI и TS обновлены, миграция таблиц не требуется.

## Догоняющая рефлексия

Планировщик уже выбирает необработанные подтверждённые эпизоды всех прошлых
UTC-суток, а не только событие перехода через полночь. Это подтверждено на новом
экземпляре production host после остановки на трое суток с исчерпанным бюджетом.
В STOPPED вызовов нет; после явного автономного START опыт подхватывается без
команды process-memory. Повторный запуск завершённый цикл не оплачивает снова.

Добавлена предварительная проверка запаса: для профиля с автономным развитием
нужны пять свободных вызовов в общем и memory-бюджете — три этапа и место для
двух story-screen при проверке/применении одной правки. Для защищённого профиля
без автономных черт остаются три. Оставшиеся три вызова не начинают новую порцию
с изменяемым характером; необработанный опыт ждёт следующего доступного бюджета.
Проверка перед каждым фактическим вызовом сохранена. Необычный ответ модели,
ошибка или неопределённый исход по-прежнему закрывают платный автоповтор.

Триггер — новые UTC-сутки и доступный бюджет. Изменение тарифа или отображаемой
стоимости не создаёт опыт и не сбрасывает счётчики. Нет обязательной рефлексии
пустого дня, повторного изменения по уже потраченным основаниям или развития
в STOPPED/observation/TEST. Сбой уже начатого платного этапа требует сверки,
а не слепого повтора при обновлении лимита. Панель объясняет догоняющий запуск.

  решений настоящей модели проверяется при использовании; script доказывает
  маршрут и ограничения, а не психологическую модель личности.

## Настройка рабочего профиля

Публичный Markdown не заменяет рабочую БД напрямую. Новые определения/значения/
границы и пояснение проявления добавляются в текущую принятую версию через
штатные persona.validate → persona.apply с actual expected_version и digest.
Существующие канон, стиль, имя и накопленные значения сохраняются. Рабочие
разговоры и личные правки в Git не переносятся. Лимит остаётся 300 в сутки,
память — в существующем резерве, автоматического START после restart нет.
