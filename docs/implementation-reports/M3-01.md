## Приёмка

| Критерий M3-01 | Результат (реальная SQLite, шлюз M2-04 mock) |
| --- | --- |
| Чужое сообщение / наблюдение / вывод разделены | сообщение → `reported` с атрибуцией «По словам X»; наблюдение → `observed`; canon только из `operator-canon`; повышение типа моделью (observed из сообщения, canon из заметки/наблюдения) понижается и фиксируется в `downgraded_from`; модель/интерпретация → `interpretation` |
| Источник проверен | цитата должна быть дословно в сохранённом тексте; неизвестный/чужой scope/удалённый/недоступный/без `api_transfer` — отказ или пропуск, в запрос не попадают; simulation только в test |
| Self-summary не даёт независимого доказательства | реплики персонажа, сводки, модельные источники: `independent_groups=0`, тип `interpretation`, уверенность ≤ 0.4; смешение с первичным источником не повышает; `Summary` не `Source` и процитироваться не может |
| Независимость | пересказ и оригинал одного эпизода — одно основание; два опыта — потолок выше (0.8 против 0.6); заявленная уверенность обрезается |
| Противоречие | обе позиции сохранены, связь с двух сторон, неизвестный `contradicts` — отказ |
| Повторы и сбои | повторная обработка без дублей; сбой/обрыв/невалидный JSON/отмена/STOP (в т.ч. между записями) ничего не пишут или останавливают дальнейшие записи; сводка после STOP не сохраняется |

Мутации защит (20): цитата, неизвестный источник, права, понижение типа и canon, self-derived,
атрибуция, потолок уверенности, группы опыта, противоречия, дубли, допуск (до/между записей/сводка),
сбой, simulation, идемпотентность и префикс сводки — каждая роняет тест; 3 эквивалентных (дубли проверок
доступности/scope, которые уже обеспечивает `get_source`).

## Решения и допущения

1. Тип знания и потолок уверенности задаёт валидатор по provenance, не модель.
2. Группа опыта = первый эпизод, содержащий источник; без эпизода источник — своя группа.
3. Коррборация из другого источника не сливается в уже сохранённую запись (id включает источники) —
   создаётся отдельное утверждение; слияние потребует версионирования источников утверждения.
4. Смысловое соответствие утверждения цитате не проверяется (только наличие цитаты).
