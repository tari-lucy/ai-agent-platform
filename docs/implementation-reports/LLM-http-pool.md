# Общий HTTP-клиент живого провайдера

Основание: поручение оператора от 2026-10-25. База: `952522b`.
Зона: транспорт OpenAI-compatible, local host, его offline-настройка и тесты.

## Результат

`serve` использует один лениво создаваемый `httpx.AsyncClient` на живой адаптер
до завершения ASGI lifespan. Сначала закрывается runtime с отменой задач,
затем клиент, включая ошибку запуска. Mock клиента не создаёт. Внедрённым
клиентом по-прежнему владеет вызывающая сторона. Прямое создание адаптера без
явного `configure_keepalive` сохраняет прежний режим клиента на один вызов.

`live.http_keepalive_seconds`: 120 по умолчанию, целое 0–3600. Старый host без
поля получает 120. Offline-команда `configure-http --root <ABS>
--keepalive-seconds 120` меняет только этот параметр под host-lock;
нужен перезапуск `serve`. При 0 общий клиент остаётся, свободные сокеты не
сохраняются. Пул ограничен четырьмя соединениями. Timeout остаётся отдельным
для каждого вызова, включая полную JSON-ветку инструментов.

Для SSE после `[DONE]` допускается одно дочитывание до HTTP EOF с пределом
50 мс: это возвращает исправный сокет в пул HTTPX. Если EOF не приходит,
ответ закрывается; маркер DONE не превращается в ошибку из-за хвоста.
Хвостовые события не передаются наружу. CancelledError не подавляется.

Cookies не сохраняются и не передаются между запросами. Bearer задаётся
каждому запросу отдельно; redirect запрещён. Новых автоматических повторов
POST нет. Кэш ответов/контекста не добавлен. Память, разрешения, версии,
TTL, ledger, бюджет и проверки STOP не менялись.

## Проверки и ограничения

- Затронутый набор `tests/llm` и `tests/local_host/test_http_transport.py`:
  135 passed. После финального уточнения порядка закрытия и SSE — отдельный
  повтор новых TCP/lifespan-тестов: **10 passed**, 38,76 с.
- `tests/local_host/test_live.py`: все четыре теста прошли в первом общем
  запуске. Он завершился с 134 passed / 5 failed: пять падений были в новых
  TCP-фикстурах из-за отсутствующего max_output_tokens. После исправления
  тест реально обнаружил непрочитанный HTTP EOF; транспорт исправлен.
- Реальный loopback HTTP/1.1: один TCP на два завершённых SSE-запроса при 120;
  новый TCP при 0, истечении срока и Connection: close; без повторного POST.
  Отмена до заголовков и во время тела закрывает запрос, но сохраняет клиент.
  DONE без HTTP EOF не зависает. Тесты не обращаются к внешней сети.
- Настоящая сборка local host: клиент закрывается после Runtime.close и при
  ошибке Runtime.open; чужой внедрённый клиент не закрывается.
- Offline-настройка: отказ под host-lock, строгая проверка диапазона/типа,
  прежние остальные настройки и побайтово прежняя БД.
- Strict mypy: 298 файлов, чисто. Ruff и diff --check — чисто.
- Независимый read-only review до уточнения EOF: блокирующих замечаний нет;
  проверены cookies, credentials, timeout, STOP, startup/shutdown.

Полный gate, Docker/UI-сборка и платные API-вызовы не повторялись: их код не
менялся. Реальное ускорение TLS/провайдера пока не измерено. Сам по себе
keep-alive не обещает конкретного времени ответа; удалённый сервер может
закрыть соединение раньше 120 секунд.
