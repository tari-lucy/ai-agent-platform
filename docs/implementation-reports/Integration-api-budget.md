# Настраиваемый лимит приватного API

Дата: 2026-10-15. База: `1bf0123`, ветка `codex/configurable-api-budget`.

По запросу оператора суточный предел подготовлен к увеличению со 100 до 300.
Убрана фиксированная верхняя бизнес-граница 100 в host-конфигурации,
серверном admission, DTO и проверке панели. Значение задаётся положительным
целым числом в локальном `host.json`, через существующую offline-команду
`configure-api-budget --attempt-limit <число> --period utc_day`.
Нулевые, отрицательные, дробные и boolean значения отклоняются.
Init по умолчанию сохраняет консервативные 10 попыток lifetime;
изменение существующего host требует явной команды и остановленного сервера.

Команда атомарно заменяет только конфигурацию, не меняет БД, usage, права,
модель или ключи. Restart не обнуляет расход и оставляет агента STOPPED.
Сутки обновляются в 00:00 UTC (03:00 Москвы). Это предел вызовов, не денег.
