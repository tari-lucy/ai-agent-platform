## Что сделано и как воспроизвести

Зона: tests/fixtures/recall и tests/probes/m0_05.
60 вручную размеченных RU запросов до первого benchmark: 48 положительных,
12 без допустимого тематического источника. Один gold chunk на positive query;
Recall@8 = средняя доля найденных gold, отрицательные не входят в знаменатель.
Даты, перефразировки, повторные встречи, обещания, исправления, гипотезы,
конфликт свидетельств и одноимённый несвязанный человек.

детерминированные тематические заметки, seed 2405. На 10k 9976 уникальных
текстов; уникальные source/chunk IDs у всех строк. Gold не менялся по результатам.

Disposable SQL adapter: prefilter work/test/persona/подтверждённого actor ID/
TTL/permissions/version **до** каждого top-k; FTS5 unicode61/cosine sqlite-vec;
RRF constant 60, 32 кандидата на ветку, source dedup, authoritative recheck
version/hash/scope перед выдачей, максимум 8. Точные открытые обещания —
отдельный ledger query без embeddings/top-k. Код не является application
schema/adapter или готовым M2/M5 lifecycle.
Constraint rowid IN проверен непосредственно на закреплённом sqlite-vec 0.1.9;
upstream описание [KNN](https://alexgarcia.xyz/sqlite-vec/features/knn.html)
относится к более новой документации, не заменяет эту проверку.

## Приёмка и ограничения

M0-05 retrieval gates пройдены на обоих размерах: Recall@8 ≥0.85,
warm p95 ≤500 ms, worker ≤1.5 GiB, provenance/scope/deletion без утечек.
Замена baseline не требуется; обязательного MemPalace/E5 сравнения нет.
FTS-only ниже quality target: это degraded fallback с явной неполнотой.
Hybrid не идеален: 3 misses на 10k записаны в results, не скрыты/переоценены.

Blind answer attribution/refusal ≥90% не проверялось: реальные LLM не
вызваны, генерация не входит в M0-05 (doc24). Negative gold доказывает
запрет источника, не способность LLM отказаться при нерелевантном контексте.
Template corpus/одна размечающая сторона не доказывают качество произвольной
биографии; нужны расширенный независимый corpus и генерационная рубрика позже.
Actor context заранее известен: resolution реальных IDs не реализован.
Workspace cross-access, API races, actual backup retention/derived summaries,
context token packaging и целевой общий WSL budget 4 GiB ещё не проверены.
Эти ограничения относятся к M1/M2/M5, не обходятся временной архитектурой.
Для M0-06 blocker нет: отдельная config validation, startup STOPPED;
не запускать агент/LLM/каналы для проверки M0-06.
