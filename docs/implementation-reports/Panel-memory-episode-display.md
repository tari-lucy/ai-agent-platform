# Отображение эпизодов памяти

2026-10-23, Codex; база `f1115da`, ветка `codex/r1-agent-session`.

Панель показывала «Часть памяти недоступна», хотя GET episodes возвращал HTTP 200.
Общий валидатор страниц требовал version у каждой записи. Episode наследует Record,
неизменяем и не имеет version; тестовая фикстура ошибочно добавляла это поле.

Для episodes допускается отсутствие version; остальные проверки области, id и схемы
сохраняются. Если version передана, она должна быть допустимой. Изменяемые sources,
claims и summaries по-прежнему обязаны иметь version. Фикстура соответствует контракту.

Проверки: 18 тестов memory.test.ts, TypeScript и сборка панели прошли на Node 24.19.
Диагностика пользовательского сервера читала только структуру ответов и технические
состояния; тексты, идентификаторы памяти и секреты не выводились и не сохранялись.

Для работающего deployment собрана его прежняя панель на базе `fa30e6f` с этой
единственной правкой валидатора и исходными generated-контрактами той же базы.
Статические assets скопированы до переключения index.html; старые assets и резервный
index сохранены локально. HTTP страницы и нового JS — 200. Код сервера, память,
permissions и конфигурация хоста не менялись. Пользовательский браузер после
обновления сборки не проверен; нужен Ctrl+F5.

Сообщение об ошибке извлечения от 16 октября — отдельная историческая запись, она
не удалялась. Текущая конфигурация сообщает memory_processing=true, сервер STOPPED.
Это не доказывает успешность следующего цикла: платные вызовы и START не выполнялись.
