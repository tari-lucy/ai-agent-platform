## Результат и границы

Один uv-проект с шестью Python packages по doc23: core, worker, contracts,
domain, application, adapters. Core/worker entrypoints проверяют установку
и завершаются. HTTP-сервера, маршрутов API, jobs, БД, схем, миграций,
Compose и логики агента нет. React-панель — статическая заглушка без API.
Реализационные решения doc07 не изменены.

Единственный владелец manifests/locks в этой задаче — исполнитель M0-02.
CPython 3.14.8 с GIL установлен в локальный игнорируемый runtime без изменения
PATH/реестра. Зависимости установлены только в .venv и node_modules.
FastEmbed/ONNX/sqlite-vec установлены как recall extra для следующей пробы;
модель не загружалась. Playwright package установлен; браузеры не скачивались.

Никаких services/ports/volumes или полного runtime не запускалось.

## Что не проверено

- Совместимость sqlite-vec load/restart и реальная RU-модель: M0-03;
  наличие wheels и импорт FastEmbed не подтверждают корректность поиска.
- Compose, Redis server/image, restart данных и общий ресурсный бюджет: M0-04.
- Recall@8 на 60 запросах/1k/10k chunks: M0-05.
- API/auth/STOP/жизненный цикл/миграции/UI-сценарии: соответствующие M1–M5 tasks.
- Browser rendering/Playwright browsers: статическая build-проверка, без browser suite.
- Уязвимости зависимостей/полный SBOM: не acceptance M0-02; потребуется до релиза.
- macOS, ARM и другие Python minor: не целевая среда этой задачи.

## Ограничения и следующие шаги

Блокирующих несовместимостей чистой установки/сборки не выявлено. Версии
sqlite-vec pre-1.0 и модельные артефакты требуют собственной пробы/фиксации,
а SQLAlchemy 2.1 и новые UI major версии — функциональных проверок в своих tasks.
Import guard проверяет только прямые статические внутренние imports и не
является sandbox. Linux recipe специально не заменяет M0-04 deployment.

Для M0-03 использовать изолированную synthetic test data, 2 CPU threads,
batch 4 и отдельный model cache; сначала download pinned revision, затем
offline tests. Зафиксировать фактические SQLite/extension versions, model
revision/checksums, RAM/cold/warm latency, delete/rebuild/restart.
Redis 8 ещё не скачивался: M0-04 должен закрепить image digest и выбранную
AGPLv3 лицензию/notice; redis-py package не доказывает серверную совместимость.
