# Integration: связность приватного разговора

База: `9fa8e87`, собственный checkout/ветка `codex/dialogue-continuity`.
Согласие оператора: передавать API Token / выбранной character-модели до восьми
последних доступных реплик, включая подтверждённые ответы. До явного согласия
эта часть была остановлена автоматическим approval review; после согласия
реализация разрешена. Секреты, личные реплики и рабочие БД в отчёт/Git не включены.

## Изменения

Storage получил ограниченный `recent(limit, before, purpose)` с порядком
created_at/id и теми же authoritative grants/ACL/TTL/deletion фильтрами.
Ни новой БД, ни обходного owner, миграций или dependencies нет.
Composition собирает последовательные `<turn>` через принятый ContextBuilder;
новый контроллер на каждом запросе больше не теряет недавний разговор.
Подтверждённая character-реплика требует совпадения точной редакции, текста,
канала и DELIVERED. Её исходные основания перепроверяются и в recall, и в истории.
Источники контекста сохраняются у производной Utterance; отзыв закрывает пересказ.
Перед вызовом и сохранением применяется существующий Execution.verify.
Выборка конечна: 200 кандидатов, до восьми реплик и 64 уникальных оснований
истории/recall плюс текущий ввод. Большие цепочки не расширяют контракт:
фрагменты с превышением бюджета пропускаются, контекст может быть неполным.
Профиль и модель не зашиты в ядро, M2 owner-модули не менялись.

## Приёмка

Первый прогон: 50 passed; четыре ошибки новых fixtures исправлены (UTC/порядок
времени, WORK provenance, уникальный request_id повторного START). Отдельный
повтор новых сценариев: 8 passed. Итоговый прогон после сохранения оснований
у производных ответов: 15 passed / 184.04 s вместе с live-wiring fake HTTP,
budget и одним настоящим браузерным mock-циклом. Реального API в этом gate нет.
Сценарии: сохранение порядка и контекста после reopen, исключение unacknowledged,
прав/удаления/TTL, отсутствие оживления через FTS, ограничение окна, чужая область,
отзыв истории во время генерации закрывает поздний результат.

Полная M5-04 (20×3) и M5-05 не закрыты. Ограниченное окно не заменяет подключение
live extraction/consolidation/reflection/GM и проверку многосессионного качества.
