Claude Code, 2026-10-24. Ветка `claude/pui-04-journey` от main `2e0dffd` (серия 1–9).
Production-код, контракты и права не менялись: поставка — проверка пути и отчёт.
Старые формы панели сохранены по указанию оператора (до переключения личного запуска);
их уборка — PUI-03, поэтому пункт «нет двух полей отправки» здесь ещё не проверяется.

## Что проверено (`tests/panel/test_native_opencode_pui04.py`)

Реальный временный host с production owners, вторая вымышленная личность Б добавлена
офлайн `add-persona`, синтетическая модель, упакованный native UI, headless Chromium.

1. У Б есть своё ждущее сообщение. А получает сообщение, после START отвечает и в этом
   ходе спрашивает оператора обращением (инструмент `raise_ticket` рабочего места).
2. Родное окно после reload говорит «Агент ждёт вашего ответа в обращении» и даёт точный
   адрес карточки `#/tickets?ticket=<id>`. Переход по нему в **той же вкладке** открывает
   карточку этого обращения; оно есть только в области А, в области Б его нет.
3. Оператор отвечает в карточке; «Назад» возвращает браузер на **тот же** разговор А
   (тот же адрес сессии), и разговор продолжается сам: ровно один новый вызов модели,
   ответ оператора в запросе, `open_ticket_ids` пуст.
4. Одно обращение владельца, вышедшее из ожидания; reload не даёт нового вызова модели и
   новой реплики. Разговор Б не тронут: его сообщение ждёт, обращений нет, слов А нет.
   Хранилище браузера пусто.

Не повторялись (закрыты OC-06, см. `test_native_opencode_journey.py`, `_sessions.py`,
`_personas.py`): STOP и отзыв основания, закрытая родная поверхность, ACK скрытого/обрезанного
ответа, неактивная Б не отвечает.

## Прогон

Linux, Python venv `integration-local-host`, `AW_NATIVE_UI_DIR` — локальная сборка серии
(патч 9 меняет только типы), панель собрана из ветки: **1 passed, 102 с**, с первого раза.
Платных вызовов нет. Windows/Edge этот путь не проверял. Адрес карточки в окне — текст
уведомления; щелчок по нему как по ссылке не проверялся, переход выполнен по точному адресу.
