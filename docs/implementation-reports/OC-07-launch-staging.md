## Перед личным включением

1. Получить независимый cross-review GLM и общий persona/native acceptance,
   исправить блокеры, принять согласованную ревизию в main.
2. Обновить preview до окончательного main; при изменении кода/патчей заменить
   соответствующие артефакты и квитанцию, проверить затронутый путь.
3. Повторить preflight, согласовать окно остановки личного serve.
4. STOP, известный исход заданий, закрытие старого serve; штатный backup с
   существующим ledger и verify; переключить launcher. Новый serve должен быть
   STOPPED, START — отдельное действие.

Независимая приёмка не подменяется зелёным preflight. Личные данные/права,
действующий launcher не менялись. Серверы, контейнеры, модели и платные API
в этом этапе не запускались. Полные тесты не повторялись; предыдущий
Windows/Docker результат — [OC-03](OC-03-render-diagnosis.md).
