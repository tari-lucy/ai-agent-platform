# Автономная приватная память и суточная рефлексия

Дата: 2026-10-15. Координатор. База `1bf0123` с принятым изменением лимита
`707fca8`; ветка `codex/live-memory-processing`.

## Что изменено

- DailyMemory подключён к существующему runtime tick. Предыдущие UTC-сутки,
  ACTIVE/OPEN/autonomous/WORK, foreground priority, ограниченные порции.
- Порция проходит принятые Extractor → Consolidator → Reflector/development
  controller. Нового owner или альтернативной памяти нет.
- Durable MemoryCycle: stage/status, ID принятых записей, digest и operation ID.
  Одинаковые порции дедуплицируются; пересекающиеся отклоняются; failed/unknown
  не запускают платные этапы повторно. При смене run технические незавершённые
  квитанции сверяются отдельно от применения результатов.
- Явный offline enable-memory переключает четыре внутренние роли на выбранную
  модель, не читает env и не выдаёт grants. Сначала проверяются все назначения;
  marker закрывает serve при незавершённом обновлении. Restart остаётся STOPPED.
- Общий лимит 300 настраивается прежней командой, резерв памяти по умолчанию 8
  входит в него. Перед каждым реальным вызовом — проверка и durable reservation.
- Согласие оператора на передачу производной памяти в API получено отдельно.
  Последняя доступная сводка/релевантные claims включаются как недоверенные
  данные с повторной проверкой оснований и общим token/source budget.
- Минимальный shared fix: Claim и Summary при создании получают уже заданные
  reader_access сервиса. Owner grants не расширены.
- Панель наблюдает циклы и резерв; точная окончательная реплика подтверждается
  автоматически лишь в видимой части активной ленты. Stream/offscreen/hidden
  не являются доставкой; ручной путь сохранён для ошибки связи.

## Границы

Модель только предлагает изменения по существующей политике профиля.
Внутренний story-screen не объявлен независимым публичным модератором.
GM, внешние инструменты, игра, голос и публичные каналы не подключались.
История сверх ограниченной выборки не обещана целиком; backlog сохраняется
и обрабатывается в пределах резерва. Ошибки требуют наблюдения, а не скрытых retry.
Квитанции MemoryCycle не содержат текста и не служат повторным источником опыта.
Backup/retention production bindings — отдельный открытый integration gate.

## Проверки

- Новые сценарии MemoryCycle: полный pipeline, атрибуция, длинная сводка в
  бюджете, повтор без rebilling, отзыв api_transfer, частичный сбой без retry,
  настоящий переход UTC-суток и обработка эпизода предыдущего run после restart.
- Production host + synthetic HTTP provider: два сценария enable-memory/guards
  и реального адаптера, четыре технических вызова, включая mock-диалог.
- Бюджет памяти: 5 проверок; contracts 87 и extraction 21 — прошли.
  Последний общий узкий прогон этих групп с UTC/restart: 114 passed.
- Regression composition/history: 14 passed. Node client: 161 passed.
- Edge production browser: 1 passed, включая offscreen→visible receipt, STOP,
  быстрый START→STOP и restart с сохранённой историей.
- Ruff, strict mypy (192 исходных файла), экспорт контрактов и сборка/lint UI — чистые.

Реальный API Token / настроенная модель: отдельный временный host, публичный
пример Опечатки и полностью вымышленный разговор. Выполнены ровно 3 платных
вызова (extractor/consolidator/reflection), все completed, usage complete:
4365 входных и 1582 выходных токена, кэш 0. Оценка по сообщённому оператором
тарифу — $0.002455; фактическое списание в рублях не сверялось. Сохранилась
одна сводка, рефлексия оставила характер без изменений, принято 0 claims.
Это проверка технического pipeline; качество извлечения и долгосрочного
развития этой единственной пробой не подтверждено. Story-screen проверен
существующими mock-сценариями; платного вызова этой роли здесь не было.

Пользовательская рабочая биография не использовалась. Пользовательские диалоги,
runtime, ключи и endpoint в Git не включаются. Полный combined suite не запускался.
