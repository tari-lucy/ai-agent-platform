# Повседневный диалог: серверные стыки

База: main f5a487e. Координатор, codex/dialogue-api-integration.

## Изменение

- Для sources, utterances, deliveries, operations добавлен явный order=desc.
  Источники упорядочены по occurred_at, остальные по created_at, затем по id.
  Строгий курсор времени/id связан с partition, ресурсом и фильтром.
  Прежнее чтение по ID без order сохранено. Миграций и новых прав нет.
- SQL применяет ACL, TTL и фильтр utterance_id до limit. Нормализация времени
  источников сохраняет микросекунды и правильный порядок на границе секунды.
- Панель открывает последние 200 записей каждого ресурса и догружает более старые.
  Обновление начинает чтение с головы; полнота и ошибки показаны явно.
- Автоматическое подтверждение использует отдельное чтение доставок точного
  ответа. Полная историческая коллекция доставок больше не обязательна.
  Дополнительные чтения ограничены 20 последними неподтверждёнными ответами
  активного run; по каждому — до четырёх страниц. При неполном/ошибочном lookup
  автоматического ACK нет, остаётся ручная кнопка. Серверные проверки сохранены.
- Состояние единственной WS-подписки выбранной области передаётся из оболочки
  в диалог. При обрыве доступно ручное перечитывание; командные POST не повторяются.
- Test subprocess helper теперь явно выбирает исходники текущего checkout
  при -I: PYTHONPATH иначе игнорировался и мог запускаться старый editable install.

## Ограничения

Курсор не является снимком БД: удаления, отзыв прав и исправления источника
видны немедленно; новая запись перед границей появляется при обновлении головы.
Страница ровно limit может потребовать дополнительную пустую страницу для
подтверждения полноты. JSON-sort источников не заявляется индексированным
или проверенным нагрузкой на большой архив. Полный suite не запускался.

## Черновик направления GM

Публичный пример profiles/examples/opechatka/gm-line.txt подготовлен по профилю:
небольшая рубрика из подтверждённых находок, уточнение своих версий и взгляда.
Он не применён к рабочему host; GM остаётся выключенным. До включения оператор
может отредактировать или подтвердить направление. Параметры включения и права
этой задачей не расширяются.
