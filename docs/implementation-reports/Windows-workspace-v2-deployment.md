## Как тестировать

1. Открыть `http://127.0.0.1:8765/opencode/`, войти обычным паролем панели.
2. В панели `http://127.0.0.1:8765/#/workspace` проверить карточку «Начальный доступ»:
   при необходимости подготовить план и подтвердить единый профиль. Новый интернет
   сам по себе разрешения не получает; прежние права не перевыданы.
3. Нажать START, затем в новом разговоре OpenCode попросить осмотреть `/workspace`
   и `/guide/tools.md`, создать пробную заметку. Для интернет-проверки использовать
   example.com, затем посмотреть журнал в панели «Работа → Интернет».
4. STOP доступен в панели. После перезапуска агент снова должен быть STOPPED.

Повторный запуск — прежний `Start-Panel.cmd` в корне проекта: он читает обновлённый
launcher. Не открывать второй сервер, пока уже запущенный работает.
Откат — остановить сервер и вернуть сохранённый launcher; миграций в пакете нет.
