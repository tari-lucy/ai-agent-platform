## Backup и переключение

Старый личный сервер уже не слушал подготовленный loopback-порт, процессов этого
host не было. Штатные `local_backup create` и отдельный `verify` — **оба exit 0**,
копия verified. Использован существующий recovery ledger, новый не создавался.
Идентификатор копии сохранён только в локальном runtime receipt, не в Git.

Перед заменой launcher проверены исходный хеш, побайтовое совпадение сохранённой
rollback-конфигурации, одинаковые host/provider/env и хеши панели/native manifest.
Активный launcher переключён на кандидат; native bundle — серия 1–9, платформа
и панель содержат OC-05 и PUI-03/04. Личный профиль, три существующих права,
назначения модели/API и бюджет не менялись. `.env` вручную не открывался;
его штатная загрузка при serve нужна существующему live-провайдеру.

Сервер запущен один раз на loopback, затем перезапущен после малой правки ссылки
ниже. Ни agent.start, ни сообщения не отправлялись, модель не вызывалась.
Данные не заменялись, restore не выполнялся. Откат launcher сохранён;
restore при необходимости использует прежний актуальный ledger и штатный preview.

## Найдено и исправлено при реальном входе

Шапка панели ссылалась на `/opencode/<directory>/`, который loader обоснованно
не отдаёт: разрешён маршрут `/opencode/<directory>/session[/id]`.
Это давало **404**, хотя native root и точные разговоры открывались.
В `860e55d` поправлен только `nativeHref` без session id; allowlist сервера
не расширялся. Unit-ожидание и браузерная проверка HTTP-статуса обновлены.

После правки: панель build + typecheck — exit 0, три native-entry unit-теста
passed. Native bundle не пересобирался: правка только в панели.
На реальном личном host в headless Edge: login → START доступен (STOPPED) →
ссылка шапки HTTP 200 → переход открывает native prompt → возврат в панель,
по-прежнему STOPPED. Browser storage пустое. Пароль прочитан только для входа,
не выводился; тексты существующих разговоров/профиля не считывались в отчёт.

## Состояние сдачи

Личный сервер работает в фоне, основной вход `/opencode/`, управление и обращения
`/`. START остаётся действием оператора. Локальная квитанция
`runtime/deployment/opencode-cutover-receipt.json` хранит хеши, backup/verify,
ревизии и факт переключения; технические логи и машинные пути вне Git.

Полный suite, платная модель и новый Docker/model journey серии 1–9 при cutover
не повторялись. Прежние проверки: настоящий Edge/Docker OpenCode на серии 1–8,
сборка/упаковка серии 1–9, Windows OC-05 и PUI-03; Linux native journeys Claude
и независимый typecheck GLM. Известные baseline vector-memory и upstream
persistence test-падения остаются отражены в отчётах; полностью зелёный общий
gate этим не объявляется. Следующий шаг — ручное использование оператором.
