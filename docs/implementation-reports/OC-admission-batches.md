# OC: пакетные чтения и результат допуска одного действия

Дата: 2026-10-25. База: `f9e3504`. Пакет оператора: первые два улучшения задержки после [предыдущего этапа](OC-response-latency.md) и отдельный замер запуска OpenCode. Платных запросов нет; память/права личного хоста не менялись.

## Изменения

- `RecordRepository.get_many`: до 200 идентификаторов, последние доступные версии через прежний SQL-фильтр scope, ACL, owner grant, TTL и зависимостей. Отсутствующие/закрытые строки не подменяются. Вызывающая сторона проверяет каждую ожидаемую ссылку и её версию.
- SQLite `read_group`: до четырёх видов записей в одном SELECT с общей прежней политикой видимости; до 200 записей каждого вида. Переполнение закрывает весь результат с RESOURCE_BUSY, а не выдаёт усечённый список прав. Применено к manifests/bindings/permissions и capability/permission. Источники для release, FileReleaseGuard и Execution.verify читаются пакетами у прежних владельцев.
- `ActionRead` — одноразовый внутренний результат успешного Policy.check. Точная команда, область, версии, epoch, задача asyncio и срок доказательства должны совпадать. После выхода из контекста результат закрыт; дочерняя задача его не получает. Execution использует уже проверенные binding/limits, вместо немедленного повторного чтения. Это не новый Permission и не кэш для следующего действия.
- Перед следующими действиями, транспортом модели, инструментами и выпуском результата остаются свежие проверки. STOP, ledger, TTL, версии, бюджет и журнал попыток не ослаблены. История/память не сокращаются. Транспорт и время жизни Docker/OpenCode не менялись.

## Проверки

- `tests/storage`, `tests/workplace_sessions/test_action_read.py`, `tests/workplace_harness/test_cold_startup.py`: **54 passed**, 11,64 с на итоговом SQL. Последний тест opt-in: существующий AW_OPENCODE_IMAGE_ID, одноразовая песочница без сети/host mounts; HTTP-заглушка модели внутри контейнера.
- Затронутый набор files, ticket release, m3 composition, gateway admission и отзыв основания во время ответа: **52 passed, 3 skipped**, 62,75 с. Пропуски — POSIX-only safe_read. Этот прогон сделан до замены промежуточного UNION на общий SELECT; после замены повторены storage и настоящий launcher.
- Реальный Docker/OpenCode launcher: **1 passed**, 49,32 с вместе с подготовкой/проверками хоста и ACK; модель синтетическая.
- Ruff изменённых Python-файлов и strict mypy всех **294 source files** чистые. Diff проверен. Полный pytest не повторялся.
- Первый mypy выявил затенённые имена в FileReleaseGuard; исправлено. Один запуск pytest без Windows elevation завис на создании event loop: остановлен только собственный процесс, проверка повторена с необходимым системным доступом. Это не таймаут приложения.

## Замеры

Одинаковый короткий сценарий production launcher с настоящим OpenCode, синтетической моделью и одноразовыми данными. Один запуск каждой версии; это диагностическое сравнение, не статистический benchmark и не обещание времени live. Вложенные интервалы не суммируются.

| Интервал | База f9e3504 | Итог |
| --- | ---: | ---: |
| Runner целиком | 15,321 с | 10,628 с |
| Gateway generate | 3,449 с | 1,559 с |
| Execution.verify, сумма 8 вызовов | 4,562 с | 2,653 с |
| tools, суммарное время | 9,287 с / 82 вызова | 3,726 с / 89 вызовов |

Runner в этой паре быстрее на 30,6%. Промежуточная реализация с UNION не помогла: 17,455 с runner и 2,778 с gateway; поэтому заменена на один SELECT с той же политикой. В фоне могли работать другие контейнеры; их не останавливали.

Отдельная холодная проба (`test_cold_startup.py`, не сложение с таблицей):

- запуск процесса OpenCode → первый запрос к внутриконтейнерной модели: **3,903 с**;
- запуск процесса → завершение CLI: **4,260 с**;
- первый запрос → завершение CLI: **0,358 с**;
- весь runner этой изолированной пробы: **6,203 с**.

Время модели в настоящем API, объём памяти и выбранные моделью инструменты добавят задержку. Повторные платные пробы не выполнялись. Постоянный прогретый runner не реализован: это отдельное изменение жизненного цикла/изоляции. В текущем этапе устраняются повторные чтения без изменения памяти и границ безопасности.
