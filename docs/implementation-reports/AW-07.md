# AW-07 — рабочий экран

Исполнитель: Claude Code. Ветка `codex/aw-07-workspace-ui`, checkout `../aw-07`, base — голова
AW-06 (`4e54c7a`), затем слит main с integrated AW-06 (`1f06e88`). Статус: **выполнено**.

## Результат

- Экран панели «10 Работа» на чтениях владельцев (без UI-only/mock проекций):
  `work-tasks`, `work-attempts` (ACTIVITY), `tickets`, `episodes`, `private-api-status`.
  Видны цель, причина, происхождение (поручение/своя цель/…), состояние, **чей ход**
  (агент; агент после запуска, если STOPPED; оператор — если ожидаемое обращение ждёт его
  ответа), шаги с результатом/отказом/неизвестным исходом, попытки (`unknown` — «исход
  неизвестен — сверяется по заданию»), результаты-файлы со ссылкой в «Библиотеку»,
  сколько шагов стало опытом (эпизоды `work-<attempt>`) со ссылкой в «Память», ожидаемые
  обращения, расход доли деятельности за день, отметка неполных/недочитанных данных.
  Навыки и знания — экран «09 Библиотека» (AW-03); обращения — «08» (AW-01).
- Команды: «Поручить» (`work.assign`) и «Отменить задачу» (`work.abandon`, новая
  `EditCommand` с `expected_version`): ревизия строится от закреплённой версии, повтор после
  обрыва с тем же `request_id` — replay, решение по устаревшему виду — `VERSION_CONFLICT`;
  шаг, который был в работе, не перезапишет отмену (его обновление закреплено своей
  версией). Один request id на черновик в обеих формах.
- `PrivateApiStatus` дополнен `activity_daily_calls`/`activity_calls_used` (0/0, пока контур
  выключен). Прямой STOP оболочки доступен на новом экране, как и на всех остальных.
