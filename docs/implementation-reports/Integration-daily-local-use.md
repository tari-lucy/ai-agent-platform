# Integration: повседневный локальный текстовый pilot

База: `9fa8e87`. Цель — удобный запуск существующего приватного host без установки
зависимостей и нового внешнего канала. Оператор выбрал 100 API-запросов в сутки.
Это не денежный бюджет; тариф/фактическое списание не выданы за измеренный расход.

## Реализовано

- OS lock на каталог host до открытия индексов/БД, включая другой порт того же
  каталога; kernel освобождает lock после завершения процесса. Файл не удаляется.
- Порт loopback резервируется до runtime.open; занятый порт не запускает recovery
  и не меняет активного supervisor. Публичный listener не добавлен.
- `serve --open-browser` открывает локальную панель один раз после готовности
  сервера, без START агента. Сбой браузера не убивает сервер.
- `Start-Panel.cmd` + `scripts/start-panel.ps1`, закрытый nonsecret config с явными
  путями. Пример в Git, локальная конфигурация игнорируется. Никаких установок,
  чтения значений .env в launcher, автозапуска агента или смены execution policy.
- `configure-api-budget` — явная offline-настройка 1..100, lifetime/utc_day.
  Журнал не очищается; число зарезервированных попыток сохраняется между restart.
  Старый host без нового поля сохраняет lifetime. Модель/permissions не меняются.
- Общий контракт PrivateApiStatus, authenticated scoped read, OpenAPI/JSON Schema/
  TS export, валидация панели, отображение остатка и следующего UTC reset.
  UI закрывает отправку на нуле; независимый backend cap остаётся обязательным.

## Короткая реальная проба API Token

Три последовательных настоящих character-запроса к выбранному `claude-sonnet-5`.
Публичный учебный профиль Опечатки, новая отдельная временная память, вымышленные
сообщения; рабочая биография не использовалась. Отдельный предел пробы — ровно
три попытки, 1024 выходных токена, без автоматического retry или fallback.

1. Представление и две детали вымышленной заметки: канон соблюдён, детали приняты,
   13.85 s до сохранённого ответа и ACK.
2. Вспоминание этих деталей следующей репликой: название маяка и день выпуска
   воспроизведены верно, 14.14 s.
3. Вопрос о настоящей публикации и неизвестном смотрителе: публикация не выдана
   за совершённую, имя не выдумано, 12.28 s. Ответ о привычном способе отправки
   заметок прочитан как профильная манера, не подтверждённая внешняя доставка.

Все три операции SUCCEEDED, точные редакции получили private receipt, финал
STOPPED. Usage complete: вход 16770, выход 768 токенов суммарно. Списание в рублях
не сверялось. По подтверждённым оператором ставкам за миллион ($0.20 вход,
$0.02 cached input, $1 выход), без скидки на кэш оценка этих трёх вызовов —
около $0.0041; это не фактическая стоимость от агрегатора.
Проверена доставка и короткая связность через этот provider binding; реальная
backend-модель агрегатора независимо не аттестована. Один трёхходовый разговор
не заменяет 20×3 rubric, разнообразие сценариев и длительную стабильность.

Windows launcher после исправления encoding только capture-fixture:
1 passed / 0.84 s. Contract suite: 87 passed / около 2 s.


## Активация текущего локального pilot

Существующий управляемый процесс подтверждён по module/root, перед обновлением
уже STOPPED, активных задач нет. Старый процесс завершён; отдельной offline-командой
установлены 100/utc_day, журнал и права не менялись. Новый normal serve поднят
на прежнем loopback с прежними рабочими данными и собранной панелью.
HTTP после restart: STOPPED, used 7, remaining 93, reset 2026-10-16 00:00 UTC;
панель отдаётся. Реальный Edge после входа показывает START, 93/100 и закрытую
отправку при STOPPED, JavaScript exceptions нет. Проверка не запускала агента
и не делала дополнительных model calls. Локальный launcher config подготовлен
в игнорируемом файле; персональные пути в Git не добавлены.

Финальный review дополнительно закрыл гонку startup/offline budget edit:
конфигурация читается под OS lock, preflight проверяет настройки/секреты один
раз, затем резервируется порт, затем открывается runtime. Сохранены прежние
машинные коды отказа для неподготовленного каталога/секретов/режима. Проверки
этих правок: budget + port 3 passed / 2.88 s, после выделения preflight guard gate
13 passed / 1 POSIX-only skip на Windows, 23.75 s; mypy/ruff чистые.
