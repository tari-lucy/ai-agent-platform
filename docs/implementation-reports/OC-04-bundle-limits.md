# OC-04: лимиты поставки родного Web UI

2026-10-23, Codex. По явному поручению оператора, база `a5071ed`, отдельная
ветка `codex/oc-04-bundle-limits`.

Packaging и loader используют общие лимиты: **1024 файла / 48 МиБ суммарно**.
Предел одного файла остаётся **8 МиБ**, manifest — **256 КиБ**. Протокол поставки
обновлён. Проверки хешей, путей, symlink/junction, overlap с host, CSP и типы
файлов не менялись. Личные настройки, deployment и права не менялись.

Проверки на временных вымышленных файлах:

- Ровно 1024 файла и 48 МиБ: prepare и load успешны.
- 1025 файлов и 48 МиБ + 1 байт: prepare отказывает.
- Суммарный размер выше 48 МиБ при корректных хешах: load отказывает.
  В первоначальной пробе хеш после изменения файла не пересчитывался, поэтому
  loader раньше отклонил digest; исправлена только проба, защита не менялась.
- Три затронутых static UI теста: **3 passed, 4.04 s**. Ruff чистый.

Полный suite, браузер, контейнеры и модели не запускались: здесь только пределы
статической поставки. Настоящий adapter dist остаётся поставкой Claude OC-03;
увеличение лимитов не доказывает готовность клиента или его происхождение.
