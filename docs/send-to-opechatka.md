# Значок «Отдать Опечатке»

Перетащите файл на значок «Отдать Опечатке» на рабочем столе: он окажется у неё в `/workspace/inbox/` на сервере.
Нужны поднятый мост до сервера (`docs/game-tunnel.md`) и запущенная Опечатка (START).

- Скрипт: `scripts/send-to-opechatka.ps1` (копия в `C:\ai-pers2\runtime\`). Значок запускает его скрытым окном и
  показывает итог окошком.
- Работает через ту же панель, что и кнопка «Отдать файл»: сессия, защита запроса (CSRF), лимит 100 МБ, безопасное
  имя, существующий файл не заменяется (появляется `имя (2)`).
- Пароль панели спрашивается один раз окошком и хранится в `%APPDATA%\ai-agent-platform\panel-password.txt` в
  зашифрованном виде, который читает только ваш пользователь Windows. Не подошёл — файл стирается и спросит снова.
  Сменили пароль панели — просто перетащите файл ещё раз.
- Папки не отправляются (заархивируйте). Консоль OpenCode потом: `@inbox/имя`.
