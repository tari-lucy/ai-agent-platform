# Передача: отладка платформы Опечатки на сервере (Claude → Codex)

Дата 2026-10-31. Автор Claude Code (его контекст на исходе). Платформа и Опечатка **уже работают на сервере**
(рабочее имя `srv-213`), а не на компьютере оператора. Здесь всё, что нужно, чтобы продолжить.
Адреса, ключи и пароли в Git не пишутся: адрес сервера и доступ даёт оператор.

## 1. Правила (не нарушать)

- Две платформы на одну личность нельзя. **Платформу и Опечатку на компе оператора не запускать**, пока работает
  серверная. Данные на компе нетронуты: это путь отката.
- STOP независим и сильнее всего. Не читать `.env` и не выводить ключи/пароли; не просить ключ в чате.
- Не делать force push/reset/clean, не удалять чужие тома/контейнеры. На сервере живёт ещё стек n8n оператора
  (7 контейнеров, у них лимиты памяти): его не трогать. Без согласия оператора не менять файрвол, sshd, Docker.
- Личные тексты (сессии, дневник, журнал постов, будильники) остаются локальными, в отчёты не попадают.
- Пакеты проверяются целевыми тестами; полный gate не нужен после каждого изменения.

## 3. Полезные команды (на сервере)

```text
systemctl --user status ai-platform ai-game-relay
journalctl --user -u ai-platform --no-pager -n 50
docker ps --filter name=aw-            # контейнеры агента (шлюз aw-hgw, агент aw-harness, выход aw-egress)
ss -tln | grep -E "4096|8765|25350"
```

Выкладка нового релиза (без GitHub-ключей на сервере): `git archive <ветка> | ssh srv-213 'mkdir -p ~/ai-platform/releases/<sha> &&
tar -x -C ~/ai-platform/releases/<sha>'`; скопировать `apps/panel/dist` из прошлого релиза (или собрать панель на машине
разработки: на сервере нет Node); перекинуть `current`; `UV_PROJECT_ENVIRONMENT=~/ai-platform/venv uv sync --locked`
**из новой папки** (иначе окружение смотрит в старый релиз); `systemctl --user restart ai-platform`. После остановки
порт 8765 занят около минуты (TIME_WAIT), служба поднимется сама. Откат: вернуть ссылку, `uv sync`, перезапуск.
Перезапуск службы останавливает работающую Опечатку: предупредить оператора.

## 4. Незавершённое (по приоритету оператора)

1. **Связь с игрой.** Цепочка контейнер → шлюз → ретранслятор → туннель → мод проверена до ответа мода (401 без токена,
   `inGame` вернул `{"ok":true}` с токеном по туннелю). Остаётся подтвердить, что Опечатка сама достаёт мод из контейнера
   (токен в `/workspace/projects/unionclef/mcp-token.txt`; адрес даёт платформа). Если нет: `journalctl --user -u
   ai-game-relay` (отказ источника пишет адрес), правило UFW `docker0 → 172.17.0.1:25350`.
2. **Кнопка «Отдать файл Опечатке»** в панели: загрузка в её `inbox/` (платформа пишет в `files_dir/<persona>/inbox`,
   ACL позволяет), лимит размера, имя без путей, без перезаписи, журнал. С тестами.
3. **Самостоятельная жизнь:** ветка `claude/life-loop` (130553a, не влита): слоты, доля бюджета, пульс, `GOALS.md`/`DIARY.md`,
   лимит постов. Влить (конфликты малы), задать `life_mode=quiet`, проверить на пробной ночи. Окно «Что делала» в панели
   и переключатель режимов ещё не сделаны.
4. **Автозапуск после перезагрузки** (D88): код в main, принят, на сервере **выключен**. Включение: остановить службу,
   `configure-harness --root ~/ai-platform/host --resume-after-restart`, запустить. Приёмка настоящей перезагрузки ОС не делалась.
5. **Копия папки Опечатки на компе:** Syncthing в одну сторону (сервер → комп), кэши исключить. Её `/workspace` не входит в
   резервные копии платформы: сейчас единственный экземпляр.
6. **Домен и сертификат** для панели/OpenCode (nginx-proxy-manager на этом же сервере; порт 81 его админки открыт наружу).
   Ждут решения оператора (домен, доступ с телефона).
7. Мелочи: быстрое освобождение порта при перезапуске службы (SO_REUSEADDR); нестабильный
   `tests/harness/test_agent_gateway.py::test_the_ui_port_relays_to_the_agent_until_stop_and_host_loss_ends_the_gateway`
   (иногда ConnectionResetError); уборка на компе (остатки контейнеров, Docker-туннель Telegram — после согласования).

## 5. Что проверено

Перенос хоста, `check-work-sessions`, резервная копия `verified=true`, START/STOP на сервере, консоль OpenCode со старыми
сессиями, файловые инструменты, восстановление после принудительной остановки (`reclaim_harness`), автозапуск D88 (Windows-ревью).
Не проверено: перезагрузка ОС сервера, длительная работа с лимитами памяти n8n-стека, сборка мода (gradle) в контейнере с
лимитом 3 ГБ, реальная публикация поста в канал (текст/голос), игра целиком.
