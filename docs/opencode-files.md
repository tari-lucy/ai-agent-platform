# Файлы агента в OpenCode

Откройте родное окно [OpenCode](http://127.0.0.1:8765/opencode/) и выберите
нужную личность и её разговор. Файлы разных личностей изолированы.

## Передать материал

1. Прикрепите файл кнопкой вложения у поля сообщения или перетащите его в окно.
2. Выберите область: `inbox` — входящие материалы; `knowledge` — справочники и
   знания; `projects` — материалы конкретной работы. Для обычной передачи
   начните с `inbox`.
3. Дождитесь сообщения об успешной передаче. Файл уже сохранён; затем отправьте
   задание, например: «Прочитай переданный файл, выдели главное и сохрани
   конспект в projects». Для исполнения агент должен быть запущен (START).

Загрузка работает и при STOPPED, но не запускает агента и не выдаёт ему новых
прав. В следующем рабочем разговорном ходе модель получает имена, ID, версии,
размеры и дайджесты доступных материалов; содержимое читает отдельным
инструментом. Публичная передача файлов загрузкой не разрешается.

## Посмотреть файлы

Вверху родного окна нажмите **«Файлы агента»** — значок дерева. Раскройте область
и нажмите имя файла. Это виртуальные области платформы, а не папки компьютера.
Просмотр текста не вызывает модель. Новые материалы обновляют открытое дерево;
при закрытом доступе старое содержимое не используется как запасная копия.

Русское исходное имя остаётся заголовком; логическое имя становится безопасным
ASCII с различающим суффиксом. Одинаковое актуальное содержимое не создаёт
лишнюю версию; изменение материала по тому же имени создаёт новую версию.
Файл агента не заменяется чужой загрузкой с совпавшим логическим путём.

На один файл — до **100 МиБ**, дополнительно действует общая квота хранилища персонажа.
Большой текст агент может читать частями по 4000 символов, сверяя версию и
дайджест. PDF, картинки и другие бинарные материалы можно хранить и видеть в
каталоге; автоматическое распознавание/разбор их содержимого этой поставкой
не добавлены. При отказе проверьте выбранную личность, квоту и её действующие
права в панели; повторная загрузка не расширяет доступ автоматически.

Для передачи новых файлов используйте вложение у сообщения. Для настройки, обращений и START/STOP остаётся
[панель](http://127.0.0.1:8765/).
