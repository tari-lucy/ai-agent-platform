# Аватар Опечатки: VTube Studio на компе, платформа на сервере

План и решения — [doc37](37-avatar-and-calls.md). Здесь шаги оператора. Аватар работает, пока
включён комп, запущен VTube Studio и поднят мост; иначе Опечатка получает фразу «аватар сейчас
недоступен» и живёт дальше текстом и голосом.

## 1. VTube Studio (комп)

1. Запустить VTube Studio, загрузить модель.
2. Настройки → «General Settings» → включить **Start API** (порт по умолчанию 8001).
3. Для подбора имён: в VTS видны хоткеи модели (Hotkeys), выражения (Expressions) и параметры
   (Settings → Model → Parameters). Нужно записать, как называются:
   - хоткей или выражение для каждой эмоции (радость, грусть, злость, удивление, раздумье,
     смущение, сонливость);
   - параметр открытия рта (обычно `MouthOpen`).

## 2. Профиль модели (сервер)

Файл `data/harness/avatar/<имя>.json` в корне host. Пример (имена замените своими):

```json
{
  "version": 1,
  "emotions": {
    "happy": {"hotkey": "Smile"},
    "sad": {"expression": "sad.exp3.json"},
    "angry": {"expression": "angry.exp3.json"},
    "surprised": {"hotkey": "Surprise"},
    "thinking": {"hotkey": "Think"},
    "embarrassed": {"parameters": {"CheekBlush": 1.0}},
    "sleepy": {"hotkey": "Sleepy"}
  },
  "neutral": {"hotkey": "Reset"},
  "mouth_parameter": "MouthOpen",
  "mouth_gain": 1.0
}
```

- У каждой эмоции любое сочетание `hotkey`, `expression`, `parameters`. Лишних ключей быть не должно.
- `neutral` — спокойное лицо: на него возвращаются при тишине, STOP и обрыве речи.
- Эмоции, для которых в профиле ничего нет, Опечатка получает ответом «нет выражения».
- Если имя из профиля не найдено в загруженной модели, об этом пишется в журнал платформы
  (`Avatar mapping does not fit the model`); эта эмоция пропускается.
- Параметры из `parameters` VTS удерживает недолго: надёжнее хоткеи и выражения.

## 3. Мост (комп ↔ сервер)

VTS (8001) нужен серверу, поэтому к мосту добавляются обратные порты (одноразово, root на сервере):

```
sudo bash install-game-tunnel-account.sh <публичный-ключ> --extra=8001 --extra=4455 --update
```

Порт 4455 нужен позже для OBS (этап A3), его можно добавить сразу. На компе в
`local.game-tunnel.json` добавить `"extra_ports": [8001, 4455]` и перезапустить задачу
(`schtasks /end`, затем `/run`, как в [game-tunnel](game-tunnel.md)). Откат: убрать `--extra`
и выполнить установщик с `--update`.

## 4. Включение (сервер, при остановленной платформе)

```
configure-harness --avatar-port 8001 --avatar-profile opechatka.json
```

Выключить: `configure-harness --remove-avatar`. Порт и профиль задаются только вместе.
При первом подключении VTS покажет окно «Allow plugin "Opechatka"?»: нажать **Allow**.
Токен плагина лежит в `data/harness/avatar/vts-token` (права 0600, в журналы не попадает).

Проверка: запустить Опечатку (START) и попросить показать радость. В VTS должно сработать
выражение; в ответе инструмента будет «Выражение: happy.».

## Что реализовано (A1) и что нет

Есть: порт `Avatar`, профиль, микшер, транспорт VTS, инструмент `avatar_express`, возврат к
нейтрали на STOP. Нет: рот по звуку речи (A2, нужно воспроизведение TTS), OBS, чаты, звонки.
