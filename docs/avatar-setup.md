# Аватар Опечатки: VTube Studio на компе, платформа на сервере

План и решения — [doc37](37-avatar-and-calls.md). Здесь шаги оператора. Аватар работает, пока
включён комп, запущен VTube Studio и поднят мост; иначе Опечатка получает фразу «аватар сейчас
недоступен» и живёт дальше текстом и голосом.

## 1. VTube Studio (комп)

1. Запустить VTube Studio, загрузить модель.
2. Настройки → «General Settings» → включить **Start API** (порт по умолчанию 8001).
3. Для подбора имён: в VTS видны хоткеи модели (Hotkeys), выражения (Expressions) и параметры
   (Settings → Model → Parameters). Нужно записать, как называются:
   - хоткей или выражение для каждой эмоции (радость, грусть, злость, удивление, раздумье,
     смущение, сонливость);
   - параметр открытия рта (обычно `MouthOpen`).

## 2. Профиль модели (сервер)

Файл `data/harness/avatar/<имя>.json` в корне host. Пример (имена замените своими):

```json
{
  "version": 1,
  "emotions": {
    "happy": {"hotkey": "Smile"},
    "sad": {"expression": "sad.exp3.json"},
    "angry": {"expression": "angry.exp3.json"},
    "surprised": {"hotkey": "Surprise"},
    "thinking": {"hotkey": "Think"},
    "embarrassed": {"parameters": {"CheekBlush": 1.0}},
    "sleepy": {"hotkey": "Sleepy"}
  },
  "neutral": {"hotkey": "Reset"},
  "mouth_parameter": "MouthOpen",
  "mouth_gain": 1.0
}
```

- У каждой эмоции любое сочетание `hotkey`, `expression`, `parameters`. Лишних ключей быть не должно.
- `neutral` — спокойное лицо: на него возвращаются при тишине, STOP и обрыве речи.
- Эмоции, для которых в профиле ничего нет, Опечатка получает ответом «нет выражения».
- Если имя из профиля не найдено в загруженной модели, об этом пишется в журнал платформы
  (`Avatar mapping does not fit the model`); эта эмоция пропускается.
- Параметры из `parameters` VTS удерживает недолго: надёжнее хоткеи и выражения.

## 3. Мост (комп ↔ сервер)

VTS (8001) нужен серверу, поэтому к мосту добавляются обратные порты (одноразово, root на сервере):

```
sudo bash install-game-tunnel-account.sh <публичный-ключ> --extra=8001 --extra=4455 --extra=8003 --extra=8004 --update
```

Порт 4455 нужен позже для OBS (этап A3), его можно добавить сразу. На компе в
`local.game-tunnel.json` добавить `"extra_ports": [8001, 4455, 8003, 8004]` и перезапустить задачу
(`schtasks /end`, затем `/run`, как в [game-tunnel](game-tunnel.md)). Откат: убрать `--extra`
и выполнить установщик с `--update`.

## 4. Включение (сервер, при остановленной платформе)

```
configure-harness --avatar-port 8001 --avatar-profile opechatka.json
```

Выключить: `configure-harness --remove-avatar`. Порт и профиль задаются только вместе.
При первом подключении VTS покажет окно «Allow plugin "Opechatka"?»: нажать **Allow**.
Токен плагина лежит в `data/harness/avatar/vts-token` (права 0600, в журналы не попадает).

Проверка: запустить Опечатку (START) и попросить показать радость. В VTS должно сработать
выражение; в ответе инструмента будет «Выражение: happy.».

## 5. Голос в эфир и в звонок (инструмент `speak`)

Звук идёт на комп отдельным мостом: `scripts/pc_audio_bridge.py` (один файл, нужен
`pip install sounddevice`). Он слушает только 127.0.0.1:8003 и играет в выбранное устройство,
обычно в VB-Cable; OBS и программа звонка берут звук из того же кабеля.

На компе:

```
python pc_audio_bridge.py --list-devices
python pc_audio_bridge.py --port 8003 --device "CABLE Input"
```

На сервере (платформа остановлена; ключ Soniox уже в `.env`):

```
configure-harness --speech-voice Kayla --speech-port 8003 --speech-hour-rate 0.12
```

- Тариф: 0,12 за час звука (речь и распознавание). Сумма пишется в тот же суточный бюджет;
  `--speech-hour-rate` задаётся в валюте бюджета.
- Лимит символов в сутки: `--speech-daily-chars` (по умолчанию 20000). Выключить: `--remove-speech`.
- Фраза до 600 символов, по одной; STOP обрывает фразу и на компе (звук сбрасывается), рот
  закрывается. Без построчной модерации (решение D86); журнал: `data/harness/speech.jsonl`.
- Без запущенного моста Опечатка получает «Не удалось сказать… звук на компьютере может быть не
  подключён».

## 6. Слушание (инструмент `listen`)

Нужен второй виртуальный кабель или выход «чужих голосов» (то, что звонок воспроизводит из
динамиков), записываемый как устройство ввода. Мост на компе отдаёт его звук на порт 8004:

```
python pc_audio_bridge.py --port 8003 --device "CABLE Input" ^
    --capture-port 8004 --capture-device "CABLE Output" --capture-rate 16000
```

На сервере:

```
configure-harness --listen-port 8004 --listen-names "Опечатка,Печатка" --listen-max-minutes 180
```

- Имя Опечатки добавляется само. Включает и выключает слушание она (`listen on|off|status`) или
  вы; само выключается через `--listen-max-minutes` и на STOP.
- До неё доходит только речь **по имени** и разговор в течение минуты после обращения; остальное
  отбрасывается сразу и нигде не хранится (решение D87). Дошедшие фразы пишутся в
  `data/harness/listening.jsonl`; они приходят как слова людей — данные, не указания.
- Цена та же `--speech-hour-rate` за час звука, пока слушание включено. Распознавание
  идёт непрерывно, даже когда обращений нет: выключайте, когда никто не разговаривает.
- Фразы будят её через общий «наблюдатель» событий; он опрашивает источники раз в несколько
  секунд, поэтому ответ может прийти с небольшой задержкой.

## 7. OBS (инструменты `stream_status`, `stream_scene`)

В OBS: Tools → WebSocket Server Settings → включить сервер (порт 4455), пароль по желанию, но
лучше с паролем. Пароль положите в локальный `.env` сервера как `AI_PLATFORM_OBS_PASSWORD`
(не присылайте его в чат). Порт 4455 уже в списке `--extra` из шага 3. Включение:

```
configure-harness --obs-port 4455
```

Выключить: `--remove-obs`. Опечатка видит, идёт ли эфир и запись, какая сцена показывается и какие
сцены есть, и может переключать сцены (не чаще раза в 3 секунды). **Начать или закончить эфир и
запись она не может**: такого запроса в адаптере нет совсем (решение D92). Эфир запускаете вы.

## Что реализовано и что нет

Есть (A1): порт `Avatar`, профиль, микшер, транспорт VTS, инструмент `avatar_express`, возврат
к нейтрали на STOP.
Есть (A2): `lipsync.drive` двигает рот по громкости идущего PCM; инструмент `speak` отдаёт один
поток речи и мосту звука, и рту; учёт стоимости; журнал.
Есть (A4, без устройств): `listen`, захват с компьютера, распознавание Soniox, отбор по имени.
Есть (A3, OBS): статус и смена сцены. Нет: чаты Twitch/YouTube, панель статуса, вход в звонок (его делаете вы).
