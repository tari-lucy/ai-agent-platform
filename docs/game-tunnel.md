# Мост комп ↔ сервер: игра и панель

Платформа и личность живут на сервере, а мод Minecraft (MCP на порту 25350) работает внутри игры на
компьютере оператора. Один постоянный SSH-мост с компьютера на сервер несёт две вещи, ничего не открывая наружу:

- **игру:** «обратный» туннель, сервер достаёт мод на компе (игровой трафик по нему не идёт, только команды мода);
- **просмотр:** панель (8765) и окно OpenCode (4096) сервера появляются на компе по тем же адресам `127.0.0.1`.

После входа в Windows мост поднимается сам, пароль и открытые окна не нужны.

```
мод (комп:25350) <- ssh -R <- сервер 127.0.0.1:25350 <- ретранслятор <- 172.17.0.1:25350
                                                      <- шлюз агента (host.docker.internal) <- контейнер Опечатки
```

## Что установлено

| Где | Что | Права |
| --- | --- | --- |
| Сервер, root (один раз; `--update` при изменении) | пользователь `aw-game-tunnel` без оболочки, ключ только его, `PermitListen 127.0.0.1:25350`, `PermitOpen 127.0.0.1:8765 127.0.0.1:4096`, `ClientAliveInterval 30` | `deploy/game-tunnel/install-game-tunnel-account.sh` |
| Сервер, пользователь | служба `ai-game-relay` (мост Docker → loopback), источники только сеть `172.17.0.0/16`, не больше 8 соединений | `deploy/game-tunnel/game_relay.py` |
| Комп, пользователь | задача Windows «AI Agent Platform - Game Tunnel» при входе, повтор каждые 15 секунд, закреплённый ключ сервера; настройки в `local.game-tunnel.json` (`port`, `bridge_ports`) | `scripts/start_game_tunnel.ps1`, `register_game_tunnel.ps1` |

Токен мода по-прежнему лежит у Опечатки (в её папке). Ретранслятор открывает порт на мосту Docker, куда
доходят и другие контейнеры сервера, но пускает только источники из сети моста по умолчанию (контейнеры
n8n живут в своей сети и отклоняются), а доступ к моду всё равно требует токена.

Если на компе уже висит вручную открытый `ssh -L 8765…`, его надо закрыть: порт занят, и мост не поднимется.

## Откат

На компе: отключить и удалить задачу «AI Agent Platform - Game Tunnel». На сервере: остановить и выключить
`ai-game-relay`; для полного удаления учётной записи убрать `/etc/ssh/sshd_config.d/81-aw-game-tunnel.conf`
и `/var/lib/aw-game-tunnel`, затем `sshd -t` и `systemctl reload ssh`.
