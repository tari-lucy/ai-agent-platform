# Проба подписки ChatGPT через собственный вход OpenCode

Временный режим. Токен подписки лежит в контейнере агента (его может прочитать она сама),
STOP и дневной лимит в деньгах на этот трафик не действуют, границей служит план ChatGPT.
Условия OpenAI на такое использование проверяет оператор.

Порядок (команда `chatgpt`, скрипт `scripts/server-chatgpt.sh`, ставится как `model`):
1. `chatgpt enable`: OpenCode получает провайдера OpenAI (служба перезапустится, агент поднимется).
2. `opencode`, затем `/connect` → OpenAI → «ChatGPT Pro/Plus (headless)»: показывает ссылку и код,
   войти в ChatGPT в браузере, ввести код. Токен сохраняется в томе агента.
3. `/models`: посмотреть имена моделей `openai/...`. Проба в одном разговоре: выбрать модель там.
4. `chatgpt on openai/<модель>`: по умолчанию всё (её работа, игра, самостоятельная жизнь,
   помощники и мелкие задачи) идёт через подписку.
5. Откат: `chatgpt off`, потом `chatgpt forget` (стирает файл входа). Платформенная модель и
   запасной список API снова основные.

Что не покрывается: запасного списка нет (упёрлись в лимит окна, запросы падают до его
сброса, переключаемся вручную `chatgpt off`); учёт расхода идёт по плану ChatGPT, не в долларах.
