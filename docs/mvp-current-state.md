# Текущее состояние текстового MVP

Сверка координатора 2026-10-19. Эта страница отделяет подключённые функции
от исторических UI-only запросов в doc24. Полная M5-приёмка ещё не объявлена.

| Область | Подключено и проверено | Следующий незакрытый стык |
| --- | --- | --- |
| Приватный разговор | Local host/панель, login, START/STOP, история по времени, точный ACK, состояние связи; реальные ответы API Token | Обычная операторская проверка качества при использовании |
| Автономная память | Суточные extract/consolidate/reflection, последние 8 реплик и производная память в контексте, диагностика циклов | Качество долгой биографии на реальном использовании |
| Сюжет и развитие | Управление GM, предложения/решения, версия/основания, ручные development controls, rollback | Живой цикл принятия/отказа персонажа; создание предложения проверено API |
| Управление памятью | Источники/утверждения/сводки/эпизоды, серверный поиск; исправление claim/summary; удаление Source через preview/execute и ledger; скачивание выбранного Source в JSON | Просмотр всей истории версий; массовый экспорт архива/медиа не реализован |
| Профиль | Редактор существующего Markdown-профиля с проверкой/применением | Удобная подготовка новых разрешённых persona scopes; остальные операции людей |
| Лаборатория | Mock-сценарии, fresh TEST pool, наблюдения/отмена, отчёты и скачивание, TEST→WORK настройки | Платный режим лаборатории не включён |
| Восстановление | Retention/ledger, ежедневные копии, guarded offline restore; selective report purge | Кнопки backup/restore в панели; полная аварийная приёмка потери host |
| Модели и расходы | Usage/unknown, попытки, общий суточный лимит (на рабочем host 300), GM/память в том же бюджете | Запись тарифов/пересчёт и удобные настройки из панели |

Следующая работа координатора: оставшиеся нужные для эксплуатации настройки
M4-07/08 и короткая итоговая операторская приёмка.
Без owner маршрута форма не считается работающей; никакие права не расширяются
ради успешной проверки. Полный M5-03 gate и M5-05 — после необходимых стыков.

M5-04 20×3 качественный прогон не проводился: оператор выбрал проверку модели
при живом использовании. Короткие разрешённые пробы записаны отдельно и не
заменяют этот gate. Работает native Windows loopback-host; полный Compose
production gate и дополнительные интеграции (игра/голос/публичные каналы) не приняты.
