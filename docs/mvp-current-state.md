# Текущее состояние текстового MVP

Сверка координатора 2026-10-20. Эта страница отделяет подключённые функции
от исторических UI-only запросов в doc24. Полная M5-приёмка ещё не объявлена.

Планирование расширения 2026-10-21: [концепция](28-agent-workplace-concept.md)
и [AW-план](29-agent-workplace-implementation-plan.md) фиксируют два контура,
самостоятельные занятия, filesystem/знания/навыки и обращения в панели.
AW-00/01/02/03/05/06/07 уже integrated в main; AW-04/09 частично реализованы,
полные gates не закрыты. Дополнение 2026-10-23: рабочий контур настроен на личном
host, стартует STOPPED; первое Permission выдаёт оператор через тикет.
Уточнение D62/D63: контур деятельности — рабочая среда самой личности;
[пересмотр AW-05/AW-08 и назначений](agent-tasks/workplace-agency-revision.md)
реализован и проверен на Linux/Windows, включая настоящий OpenCode и браузерный ACK.
[Deployment, проверки и ограничения](implementation-reports/Deployment-workplace-opencode.md).
Приведённые ниже факты/ограничения основного MVP этим не отменяются.

| Область | Подключено и проверено | Следующий незакрытый стык |
| --- | --- | --- |
| Приватный разговор | Local host/панель, login, START/STOP, история по времени, точный ACK, состояние связи; реальные ответы API Token | Обычная операторская проверка качества при использовании |
| Автономная память | Суточные extract/consolidate/reflection с подхватом после STOP/обновления бюджета, последние 8 реплик; поиск старых claims/сводок, ограниченная биография, выдержки и месячный дайджест; backlog и продолжение доказанно сбойного этапа | Качество долгой биографии на реальном использовании; основания StateChange/Episode пока не переносятся на выдержки |
| Сюжет и развитие | Управление GM, предложения/решения, версия/основания, ручные development controls, rollback; у Опечатки шесть bounded черт | Живой цикл принятия/отказа персонажа; создание предложения проверено API |
| Управление памятью | Источники/утверждения/сводки/эпизоды, серверный поиск; исправление claim/summary; удаление Source через preview/execute и ledger; скачивание выбранного Source в JSON | Просмотр всей истории версий; массовый экспорт архива/медиа не реализован |
| Профиль и люди | Редактор Markdown-профиля; подтверждённый вход панели как постоянный собеседник, встречи и точные обещания; закрытие обещания оператором, последующий опыт рядом с изменением характера | Удобная подготовка новых persona scopes; закрытие обещаний моделью не подключено, качество проявления черт не оценивается автоматически |

| Восстановление | Retention/ledger, ежедневные копии, guarded offline restore; selective report purge | Кнопки backup/restore в панели; полная аварийная приёмка потери host |
| Модели и расходы | Usage/unknown, попытки, общий суточный лимит (на рабочем host 300), GM/память в том же бюджете; изменение лимита и запись версий тарифов из панели | Исторический пересчёт, редактирование назначений моделей; сверка со счётом провайдера |

Следующая работа координатора: оставшиеся нужные для эксплуатации настройки
M4-07/08 и короткая итоговая операторская приёмка.

ради успешной проверки. Полный M5-03 gate и M5-05 — после необходимых стыков.

Raw-разговор остаётся на 30 дней; значимые дословные выдержки ограничены 600
символами и 365 днями от события, подготовка начинается за 7 дней до TTL.
Недопустимое/непокрытое основание не продлевается. Дайджест — интерпретация,
не новый независимый опыт; исходные сводки автоматически не удаляются.
Обновление не запускает персонажа и не даёт публичных/игровых полномочий.
