# Building kit: стройка в Minecraft для ИИ-агента через UnionClef

Набор скриптов и инструкция, которые позволяют ИИ-агенту построить дом (и не только) в Minecraft:
найти ровную площадку, выровнять её, описать постройку кодом, проверить форму до стройки, построить,
убрать за собой леса и осмотреть результат. Всё работает через мод **UnionClef** (его MCP-сервер).
Пакет вырос из платформы ИИ-персонажей «Опечатка» и от неё не зависит.

Идея, на которой он держится: **модель не расставляет блоки**. Она придумывает замысел и принимает
решения, код считает геометрию и проверяет её, мод исполняет и честно сообщает, что не вышло.

## Что нужно

- Minecraft **1.21.11** на Fabric и мод **UnionClef в нашем форке** (в апстриме нет части инструментов,
  см. [MOD.md](MOD.md)).
- Python **3.10+**, внешних библиотек нет.
- Агент (любая модель), которому можно запускать команды в консоли. Желательно со зрением: он смотрит
  картинки чертежа и кадры постройки. Без зрения работают всё, кроме осмотра по картинкам.
- Токен и адрес MCP-сервера мода.

## Установка за 10 минут

1. Поставь мод (см. MOD.md), запусти игру, зайди в мир.
2. Скопируй `kit.env.example` в `kit.env`, впиши адрес и токен мода.
3. Проверь связь: `python3 scripts/check_setup.py`. Скрипт скажет, отвечает ли мод и каких инструментов
   не хватает для каждой команды.
4. Дай агенту [GUIDE_FOR_THE_MODEL.md](GUIDE_FOR_THE_MODEL.md) (в системный промпт или как файл
   инструкций) и разреши запускать `python3 scripts/...`.
5. Скажи агенту: «построй небольшой домик рядом со мной».

## Проверка без игры

В пакете есть игра-заглушка с игрушечным миром. Она быстро прогоняет всю цепочку и ничего не требует:

```
python3 scripts/mock_mcp.py --scaffold --hills &       # слушает http://127.0.0.1:25350/mcp, токен SECRET
cp kit.env.example kit.env && sed -i 's/^UNIONCLEF_MCP_TOKEN=.*/UNIONCLEF_MCP_TOKEN=SECRET/' kit.env
python3 scripts/check_setup.py
python3 scripts/build_plan.py site 7x9 --near 10,10            # найти площадку
python3 scripts/build_plan.py lint examples/gazebo/plan.txt    # проверка формы
python3 scripts/build_plan.py picture examples/gazebo/plan.txt # картинка чертежа в shots/
python3 scripts/build_plan.py stock examples/gazebo/plan.txt --origin 40,65,40
python3 scripts/build_plan.py build examples/gazebo/plan.txt --origin 40,65,40
```

Заглушка не мод: она ставит блоки мгновенно и не показывает настоящих проблем игры (зависания,
дальность, защиту). Это проверка, что скрипты связаны правильно.

## Команды `scripts/build_plan.py`

| Команда | Что делает |
|---|---|
| `site 7x9 [--near X,Z] [--radius 24]` | находит ровную площадку без воды, лавы и деревьев, с запасом по краям, называет готовый `--origin` |
| `level план --origin X,Y,Z` | выравнивает участок до высоты Y-1: низкое досыпает, высокое срезает |
| `lint план` | проверка формы: висящие блоки, асимметрия, дыры, замурованный свет, тяжёлая крыша |
| `picture план` | картинка чертежа с четырёх сторон (в папку `shots`), её смотрит модель до стройки |
| `check план --origin ...` | материалы, габариты, проверка формы |
| `stock план --origin ...` | выдаёт недостающие материалы командой `/give` (только где есть читы) |
| `build план --origin ...` | строит по этапам (до 9 видов блоков, по числу ячеек хотбара), в конце сам убирает леса и сверяет |
| `build ... --mode commands` | мгновенно, командами `/fill` и `/setblock` (только где есть права на команды) |
| `verify план --origin ...` | сверяет мир с чертежом |
| `cleanup план --origin ...` | разбирает за строителем всё лишнее вокруг постройки и достраивает забранное |
| `review план --origin ...` | четыре кадра готовой постройки с углов, их смотрит модель |
| `dig план --origin ...` | копает (в схеме `. = выкопать`): подвал, нора; отказывается, если рядом вода, лава, песок или гравий |

Схема постройки это текстовый файл со слоями (формат в начале `scripts/build_plan.py`), а собирает её
из деталей Python-библиотека `scripts/blueprint.py` (пример: `examples/gazebo/gazebo.py`).

## Что внутри

```
scripts/blueprint.py     библиотека форм: пол, стены, крыши, арки, колонны, цилиндры, зеркало, поворот
scripts/recipes.py       готовые заготовки: дом, башня, беседка, мост, стена, фонтан, пирамида
scripts/design_check.py  проверка формы и картинка чертежа (PNG без внешних библиотек)
scripts/terrain.py       поиск площадки и расчёт выравнивания
scripts/build_plan.py    оркестратор всех команд выше
scripts/mcp_client.py    клиент к MCP мода; goto_wait.py и shot.py: дойти до точки, снять кадр
scripts/check_setup.py   проверка установки; mock_mcp.py: игра-заглушка
GUIDE_FOR_THE_MODEL.md   инструкция для самой модели: порядок стройки, правила дизайна, ограничения
examples/gazebo/         готовый пример: схема, скрипт, картинка чертежа
```

## Честные ограничения

- Блоки с направлением (лестницы, двери, кровати, таблички) мод пока ставит в положении по умолчанию:
  крыша выходит ступенчатой из целых блоков, двери делаются проёмом.
- Добыча материалов в режиме выживания по плану не автоматизирована: `stock` выдаёт материалы командой
  (нужны читы), без них блоки должен положить в хотбар человек или агент добудет сам другими средствами.
- На чужих серверах не проверялось: там защита территории, свои правила и другие команды. Строй только
  там, где можно.
- Пакет проверен на тестах и на заглушке; в настоящей игре главный сценарий (дом, беседка) пройден,
  но сложные места (крутые склоны, большие постройки) требуют внимания.
