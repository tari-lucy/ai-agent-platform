# Мод UnionClef для этого пакета

Пакет говорит с игрой через **MCP-сервер мода UnionClef** (бот altoclef и движение tungsten для Fabric).
Нужна версия **Minecraft 1.21.11, Fabric**.

## Какой именно мод

**Форк** `tari-lucy/unionclef` (ветка `screenshot-tool`), который добавляет инструменты, нужные
стройке. В апстриме (`3ndetz/unionclef`) их нет, и часть команд пакета в нём не заработает.

| Инструмент мода | Для чего | Есть в апстриме |
|---|---|---|
| `getHeightmap` | `site`, `level`: карта высот области за один вызов | нет |
| `scanBox` | `cleanup`: все блоки области за один вызов | нет |
| `getHotbar` | проверка материалов, `stock` | нет |
| `sendGameCommand` | `stock`, `--mode commands` (`/give`, `/fill`) | нет |
| `mineBlocks` | `dig`, `level` (срез), `cleanup` | нет |
| `creativeTakeBlock` | положить блок в хотбар в творческом режиме | нет |
| `buildBlocks`, `buildQueue`, `cleanupScaffold`, `mineStatus`, `takeScreenshot`, `lookAt`, `gotoXYZ`, `pathStatus` | основа стройки, осмотр | есть |

Кроме инструментов, в форке исправлены два зависания строителя: он перекладывает нужный стак из рюкзака
в хотбар и больше не встаёт в клетки, которые сам должен построить.

`python3 scripts/check_setup.py` покажет, чего у твоей сборки мода не хватает.

## Где взять

- Исходники: https://github.com/tari-lucy/unionclef, ветка `screenshot-tool` (коммиты `4077ea24`,
  `1d030906`, `54d99df0`). Сборка описана в `docs/DEVELOP.md` репозитория мода.
- Готовый файл (`.jar`) положи в папку `mods` игры. Должен лежать **один** файл `unionclef…jar`:
  если рядом старый, игра может загрузить его вместо нового (одинаковые имя и версия внутри).

## Токен и адрес

В настройках мода (`altoclef_settings.json`) задаются `mcpPort` (по умолчанию 25350) и `mcpAuthToken`.
Впиши их в `kit.env`. Если агент на другой машине, пробрось порт (например, `ssh -L 25350:127.0.0.1:25350`).
