# Линейные миграции M1-02

Единственная цепочка: `0001` (области и grants) → `0002` (записи,
редакции, связи источников, ACL, уникальности, outbox, квитанции).

Ревизии — неизменяемые снимки. Следующее изменение схемы получает новый номер
после интеграции. Downgrade с уничтожением данных намеренно не предоставлен.
Миграция выполняется явно администратором через `SQLiteStore.upgrade(path)`;
обычное открытие проверяет ревизию и отказывает при несовпадении.
Путь к этим файлам передаётся явно; `.env` не читается.

Перед обновлением рабочей БД нужен согласованный backup/restore процесс M5;
проверки M1-02 используют только синтетические отдельные БД.
